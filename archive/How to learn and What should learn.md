# 数学建模三十二种方法：竞赛重点、知识缺口与补充算法

> 用法：本文件不是把低频方法删除，而是区分“必须掌握”“按题型备用”和“书中讲得太少、但可能决定成绩”的内容。时间紧时，优先看每章的 **竞赛关键补充**。

## 一、先记住：国一与普通完成题的差距

书中的算法只是工具。竞赛中真正拉开差距的通常是：

1. **问题抽象**：把题目拆成对象、变量、机制、目标和约束，而不是见到数据就套回归。
2. **假设有依据**：每条假设说明为什么合理，并说明可能造成的影响。
3. **模型链条完整**：数据预处理 → 子问题建模 → 参数估计 → 求解 → 验证 → 敏感性/稳健性分析。
4. **模型比较**：至少准备两个合理模型，用误差、稳定性、解释性和复杂度比较，而不是只报一个最优值。
5. **验证可信**：留出验证、交叉验证、回代检验、残差分析、极端情形检验、扰动分析至少做一部分。
6. **不确定性表达**：给区间、置信度、误差条、情景分析，而不是只给一个精确到小数点后很多位的数字。
7. **可解释的结论**：回答“为什么”“哪些因素最重要”“参数变化后怎么办”，不能只贴算法输出。
8. **可复现**：代码、随机种子、数据清洗规则、参数表、图表和关键中间结果能被复核。

## 二、逐章竞赛清单

### 第1章 线性规划

**必须掌握**：决策变量、目标函数、约束；绝对值和 max/min 线性化；运输、指派、投资组合；对偶与灵敏度；Matlab/LINGO/Python 求解。

**竞赛关键补充**：

- 逻辑约束线性化：互斥、蕴含、至少/至多、固定费用、分段线性成本。
- 大 M 法的取值、数值稳定性和替代写法。
- 多目标线性规划：加权和、ε-约束、词典序优化。
- 松弛解、整数上界、影子价格和资源瓶颈解释。
- 求解器状态、不可行/无界诊断，以及结果回代检查。

**书外补学**：分支定界、分支切割、割平面、内点法、MILP 求解器（Gurobi/CPLEX/SCIP/OR-Tools）。

### 第2章 整数规划

**必须掌握**：0-1 建模、互斥/逻辑条件、固定费用、分枝定界、指派和生产销售计划。

**竞赛关键补充**：有效上界/下界、对称性消除、Big-M 选取、不可行诊断、整数解与线性松弛解的差距。

**书外补学**：Branch-and-Cut、Branch-and-Price、列生成、集合覆盖/集合划分模型、约束规划 CP-SAT。

### 第3章 非线性规划

**必须掌握**：凸性、无约束/约束优化、二次规划、罚函数、局部与全局最优。

**竞赛关键补充**：变量尺度统一、初值敏感性、多初值重复运行、约束可行性、KKT 条件、局部最优陷阱、正则化。

**书外补学**：SQP、信赖域、坐标下降、ADMM、差分进化（DE）、粒子群（PSO）、CMA-ES、贝叶斯优化。

### 第4章 动态规划

**必须掌握**：阶段、状态、决策、状态转移、递推方程、逆序求解；最短路、资源分配、生产计划、背包。

**竞赛关键补充**：状态设计、状态压缩、滚动数组、路径回溯、连续状态离散化误差、维数灾难和剪枝。

**书外补学**：记忆化搜索、A*、有限元式状态离散、强化学习中的 Bellman 方程、近似动态规划。

### 第5章 图与网络

**必须掌握**：最短路、最小生成树、最大流最小割、最小费用流、匹配、邮递员、TSP。

**竞赛关键补充**：建图规则、节点/边权含义、不可达处理、路径回溯、网络容量与流量守恒、复杂度分析。

**书外补学**：A*、双向 Dijkstra、Dinic、费用流势函数、KM 算法、Hungarian 扩展、Tarjan 强连通分量、拓扑排序、关键路径、最小割建模。

### 第6章 排队论

**必须掌握**：泊松到达、指数服务、M/M/1、M/M/s、损失制、等待制、利用率、等待时间、系统容量设计。

**竞赛关键补充**：参数从数据估计、稳态条件检查、有限容量、优先级/多类别顾客、成本—服务水平联合优化、仿真验证。

**书外补学**：离散事件仿真、蒙特卡洛排队仿真、M/G/1、G/G/1、Jackson 网络、排队网络近似。

### 第7章 对策论

**必须掌握**：收益矩阵、纯/混合策略、鞍点、零和博弈线性规划、纳什均衡基本概念。

**竞赛关键补充**：明确参与者、信息结构、同时/先后行动；区分竞争模型与普通多目标优化；解释均衡的现实含义。

**书外补学**：Stackelberg 博弈、演化博弈、复制动态、拍卖机制、双层规划、均衡约束数学规划（MPEC）。

### 第8章 层次分析法

**必须掌握**：层次结构、判断矩阵、权重、一致性检验、总排序、敏感性分析。

**竞赛关键补充**：指标正向化、标准化、主客观权重结合、判断矩阵来源说明、权重扰动稳健性、避免重复计权。

**书外补学**：熵权法、CRITIC、标准离差权、TOPSIS、VIKOR、PROMETHEE、BWM、组合赋权、模糊 AHP。

### 第9章 插值与拟合

**必须掌握**：Lagrange、Newton、分段线性、Hermite、样条、插值误差、插值与拟合区别。

**竞赛关键补充**：禁止盲目高阶插值；区分插值、外推、平滑；异常值处理；边界效应；交叉验证和误差图。

**书外补学**：LOESS/LOWESS、Savitzky–Golay、径向基函数插值、克里金/高斯过程回归、正则化最小二乘。

### 第10章 统计描述与分析

**必须掌握**：描述统计、分布、估计、置信区间、假设检验、相关性、异常值。

**竞赛关键补充**：数据质量审计、缺失值机制、异常值诊断、正态性/方差齐性检验、效应量、Bootstrap、置信区间而非只报 p 值。

**书外补学**：Bootstrap、置换检验、Mann–Whitney、Wilcoxon、K-S 检验、稳健统计、缺失数据多重插补、因果前的混杂检查。

### 第11章 方差分析

**必须掌握**：单因素、双因素、交互效应、F 检验、多重比较、方差分析表。

**竞赛关键补充**：实验设计、随机化、重复、区组设计、效应量、残差诊断、方差不齐时的 Welch ANOVA。

**书外补学**：正交试验设计、响应面法、Taguchi 方法、ANCOVA、广义线性模型。

### 第12章 回归分析

**必须掌握**：一元/多元回归、最小二乘、(R^2)、显著性、残差、预测、非线性变换、标准化。

**竞赛关键补充**：共线性（VIF）、变量选择、正则化、残差独立性/同方差性、训练—验证划分、预测区间、模型解释。

**书外补学**：Ridge、Lasso、Elastic Net、Logistic 回归、广义线性模型、稳健回归、分位数回归、GAM、混合效应模型。

### 第13章 微分方程建模

**必须掌握**：建模假设、状态变量、Malthus、Logistic、资源、人口、战争、传染和竞争模型。

**竞赛关键补充**：参数辨识、无量纲化、初值/边界条件、稳态、灵敏度、相图、模型校准和现实约束。

**书外补学**：SIR/SEIR、Lotka–Volterra、反应动力学、状态空间模型、参数反演、最小二乘/贝叶斯校准。

### 第14章 稳定状态模型

**必须掌握**：平衡点、Jacobian、特征值、局部稳定、资源、竞争、捕食—被捕食、Volterra。

**竞赛关键补充**：稳定性不是“算出平衡点”就结束；要说明扰动后行为、参数阈值、分岔和管理策略。

**书外补学**：Lyapunov 方法、分岔分析、相平面数值轨迹、灵敏度方程。

### 第15章 常微分方程数值解

**必须掌握**：Euler、改进 Euler、RK4、方程组、高阶方程转一阶、步长和误差。

**竞赛关键补充**：收敛性验证、步长敏感性、守恒量检查、刚性识别、数值解与解析/实验数据对比。

**书外补学**：自适应 Runge–Kutta、BDF、shooting 法、边值问题、有限差分边值法。

### 第16章 差分方程

**必须掌握**：递推关系、离散增长、蛛网模型、预测、稳定性、周期和发散。

**竞赛关键补充**：离散化误差、采样周期选择、滞后结构、状态约束、参数变化后的稳定区间。

**书外补学**：ARIMA 差分思想、状态空间离散模型、Logistic 映射、元胞自动机、离散事件模型。

### 第17章 马氏链

**必须掌握**：状态、转移矩阵、多步转移、稳态分布、吸收链、吸收时间。

**竞赛关键补充**：转移概率的估计、时间齐次假设检验、状态合并、稳态是否存在、初始分布敏感性。

**书外补学**：隐马尔可夫模型 HMM、马尔可夫决策过程 MDP、PageRank、蒙特卡洛马尔可夫链 MCMC。

### 第18章 变分法

**必须掌握**：泛函、Euler–Lagrange 方程、端点条件、约束变分、最短曲线/最小能量。

**竞赛关键补充**：先判断问题是否真的需要连续轨迹优化；明确边界、控制量、约束和可行性；与离散优化比较。

**书外补学**：最优控制、Pontryagin 极大值原理、直接配点法、有限元变分思想。

### 第19章 神经网络

**必须掌握**：网络结构、激活函数、BP、损失函数、训练/测试、归一化、过拟合。

**竞赛关键补充**：小样本不能盲目深度学习；交叉验证、早停、正则化、重复实验、特征重要性、预测区间。

**书外补学**：随机森林、XGBoost、LightGBM、KNN、决策树、朴素贝叶斯、CNN/LSTM（只有数据规模和题型允许时使用）。

### 第20章 偏微分方程数值解

**必须掌握**：椭圆/抛物/双曲型、边界初值、有限差分、热传导、扩散、波动、稳定性。

**竞赛关键补充**：网格独立性、边界条件物理意义、守恒性、稳定性与精度的权衡、参数反演和实验校准。

**书外补学**：有限元法 FEM、有限体积法 FVM、谱方法、Crank–Nicolson、ADI、PDE 反问题。

### 第21章 目标规划

**必须掌握**：正/负偏差、目标约束、优先级、权重、序贯优化、多目标模型。

**竞赛关键补充**：先判断目标之间是否可加权；量纲统一；权重/优先级敏感性；报告 Pareto 前沿而不是单一权重结果。

**书外补学**：ε-约束法、NSGA-II、MOEA/D、理想点法、鲁棒多目标优化。

### 第22章 模糊数学

**必须掌握**：隶属函数、模糊集合、模糊关系、模糊矩阵、模糊综合评价、模式识别。

**竞赛关键补充**：隶属函数不能凭感觉；给出阈值来源、专家依据或数据拟合；做隶属函数敏感性分析。

**书外补学**：模糊 AHP、模糊 TOPSIS、模糊聚类、ANFIS、模糊控制、区间/直觉模糊集。

### 第23章 现代优化算法

**必须掌握**：模拟退火、遗传算法、禁忌搜索、编码、适应度、邻域、参数、收敛和多次运行。

**竞赛关键补充**：算法不是越复杂越好；必须有基准解/下界、重复运行、随机种子、参数敏感性和停止准则。

**书外补学**：PSO、差分进化 DE、蚁群 ACO、NSGA-II、MOEA/D、CMA-ES、混合启发式、局部搜索、VNS。

### 第24章 时间序列

**必须掌握**：移动平均、指数平滑、趋势、季节、自相关、预测误差。

**竞赛关键补充**：时间顺序不能随机打乱；滚动预测；训练集/测试集按时间切分；残差白噪声；预测区间和突变处理。

**书外补学**：AR、MA、ARMA、ARIMA、SARIMA、VAR、状态空间/Kalman、Prophet、GARCH、LSTM。

### 第25章 存贮论

**必须掌握**：EOQ、订货周期、补货提前期、缺货、生产批量、数量折扣、资金和库容约束。

**竞赛关键补充**：随机需求、安全库存、服务水平、供应不确定性、敏感性分析、多品种联合订货。

**书外补学**：((s,S)) 策略、Newsvendor、随机库存动态规划、鲁棒库存、仿真优化。

### 第26章 经济与金融优化

**必须掌握**：供需均衡、拍卖投标、交通流均衡、收益—风险、投资组合、交易成本。

**竞赛关键补充**：市场机制假设、风险度量选择、协方差稳定性、情景分析、极端风险、无风险利率和交易约束。

**书外补学**：均衡约束优化、Black–Litterman、CVaR、VaR、鲁棒投资组合、网络均衡算法。

### 第27章 生产与服务运作管理

**必须掌握**：多级生产、瓶颈、物料需求、下料、切割、调度、消防车/飞机定位。

**竞赛关键补充**：业务流程抽象、库存平衡、能力瓶颈识别、切割模式生成、方案可执行性和整数性。

**书外补学**：列生成、Gilmore–Gomory 下料、车辆路径 VRP、带时间窗 VRPTW、设施选址、最大覆盖、仿真调度。

### 第28章 灰色系统

**必须掌握**：无量纲化、AGO、关联分析、关联系数、GM(1,1)、GM(1,N)、残差和后验检验。

**竞赛关键补充**：小样本不等于无条件使用灰色模型；必须和 ARIMA、回归或指数平滑比较，并报告滚动误差。

**书外补学**：灰色—回归组合、灰色—神经网络组合、灰色 Verhulst、滚动 GM、贝叶斯模型平均。

### 第29章 多元分析

**必须掌握**：标准化、距离、系统聚类、变量聚类、主成分、降维、判别、综合评价。

**竞赛关键补充**：标准化方式影响结果；聚类数选择；PCA 不能替代解释；聚类稳定性和外部验证。

**书外补学**：K-means、K-medoids、DBSCAN、GMM、谱聚类、t-SNE/UMAP、LDA 判别、因子分析。

### 第30章 偏最小二乘回归

**必须掌握**：标准化、潜变量、共线性、小样本、多响应回归、成分数和交叉验证。

**竞赛关键补充**：成分数不能凭经验；报告预测误差、VIP、变量解释和与 Ridge/Lasso/PCR 的比较。

**书外补学**：稀疏 PLS、核 PLS、PCR、Elastic Net、Bootstrap 置信区间。

### 第31章 支持向量机

**必须掌握**：最大间隔、支持向量、软间隔、核函数、C、γ、SVM 回归、交叉验证。

**竞赛关键补充**：类别不平衡、特征缩放、数据泄漏、训练/测试切分、混淆矩阵和 ROC-AUC。

**书外补学**：Random Forest、XGBoost、LightGBM、CatBoost、核岭回归、One-Class SVM、校准概率。

### 第32章 作业计划

**必须掌握**：流水车间、作业车间、Johnson、完工时间、整数规划、启发式、甘特图。

**竞赛关键补充**：机器冲突、工序先后、不可中断、换型时间、交货期、迟期惩罚、调度方案可执行性。

**书外补学**：Job-shop CP-SAT、遗传/禁忌/模拟退火混合调度、关键路径法 CPM、PERT、滚动调度、鲁棒调度。

## 四、国赛论文中最容易被忽略、但决定上限的部分

### 建模前

- 把题目要求拆成“预测、评价、优化、解释、控制”中的一种或多种。
- 明确每个符号、单位、时间尺度、空间尺度。
- 检查数据是否存在缺失、重复、异常、量纲不一致和信息泄漏。

### 建模中

- 约束必须能回到题目原文，不能为了让模型可解而偷偷删约束。
- 任何权重、阈值、惩罚系数、初值、步长都要说明来源。
- 对关键参数做敏感性分析，说明结论是否稳健。
- 优化问题必须检查可行性、整数性、边界解和局部最优。
- 预测问题必须做回测、留出验证或滚动预测。

### 建模后

- 做误差分析、残差分析、极端情景和扰动实验。
- 至少给出一个基准模型或替代模型作为比较。
- 不只展示“最优值”，还要展示方案、资源利用率、瓶颈、代价和可执行性。
- 图表要服务于论证：趋势图、残差图、敏感性图、Pareto 图、甘特图、路径图、收敛图。
- 结论要回答题目问题，并指出模型适用范围和局限性。

## 五、时间极紧时的学习顺序

### 第一优先级

线性规划 → 整数规划 → 回归 → 统计检验 → 插值拟合 → 动态规划 → 图与网络 → 非线性规划 → 微分方程 → 现代优化。

### 第二优先级

时间序列 → 灰色系统 → AHP/熵权/TOPSIS → 多元分析/PCA → 目标规划 → 常微分方程数值解 → 作业计划。

### 第三优先级

排队论、马氏链、模糊数学、对策论、存贮论、生产运作、SVM、神经网络、PDE、变分法、经济金融优化、PLS。

> 最终原则：算法本身通常只占论文的一部分；“问题抽象、假设、验证、稳健性、解释和写作”才是决定能否从完成题上升到国一的关键。
