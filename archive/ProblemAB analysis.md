# 全国大学生数学建模竞赛 A/B 题知识算法矩阵（2016-2025）

> 依据 `Problems/` 中 2016-2025 年题面整理。2016A 的 doc 文本编码有乱码，已按题面标题与可辨识结构核对为“系泊系统设计”。

## 总判断

1. **A 题主线是机理 + 几何 + 数值计算**：多数年份都需要先建立物理或几何模型，再离散化、反演参数或优化设计。
2. **B 题主线已经分化**：一部分是传统运筹/决策/调度，另一部分是几何、光学、信号与反问题。只练整数规划和启发式算法不足以覆盖近年 B 题。
3. **A/B 共同底层能力**：数值几何、非线性方程、参数反演、仿真验证、约束优化、误差与敏感性分析。
4. **最值得优先训练**：3D 向量几何、ODE/PDE 数值解、非线性最小二乘、离散事件/动态规划、全局优化、结果稳健性检验。

## 共用能力栈

### 1. 数值几何与物理机理

必须熟练：

- 向量点积、叉积、旋转矩阵、球面/平面/圆柱面表示。
- 反射定律、视线遮挡、光线追踪、线段相交、碰撞检测。
- 量纲检查、守恒律、受力分解、刚体运动学。
- 把题目叙述直接翻译为方程组，而不是先套模型。

覆盖题目：2017A、2021A、2022B、2023A、2023B、2024A、2025A。

### 2. 微分方程与连续系统仿真

必须熟练：

- 常微分方程初值问题、刚性方程、周期激励与稳态判断。
- 热传导一维 PDE、边界条件、多层界面。
- 非线性阻尼、耦合自由度、能量与平均功率计算。

覆盖题目：2018A、2019A、2019B、2020A、2022A、2025A 的运动学部分。

### 3. 参数反演与数据拟合

必须熟练：

- 非线性最小二乘、残差设计、初值选择。
- 从观测数据反推物理参数或几何参数。
- 过拟合与不适定问题识别、正则化、稳定性检验。

覆盖题目：2017A、2018A、2021B、2022B、2025B。

### 4. 优化与决策

必须熟练：

- 约束非线性优化、混合整数规划、动态规划。
- 离散事件仿真、滚动时域、鲁棒/随机决策。
- 多目标优化与 Pareto 前沿。

覆盖题目：2016A/B、2018B、2020A/B、2023A/B、2024B、2025A。

### 5. 统计、光谱与不确定性

必须熟练：

- 假设检验、置信度、抽样方案、贝叶斯更新。
- 光谱峰谷提取、频域分析、非线性曲线拟合。
- 误差传播、敏感性分析、结果可靠性表述。

覆盖题目：2017B、2021B、2024B、2025B。

## 训练优先级

### P0：比赛基础，必须达到“断 AI 可写”

1. Python 科学计算：`numpy`、`scipy`、`pandas`、`matplotlib`。
2. 非线性方程与最小二乘：`root`、`least_squares`。
3. ODE 数值解：`solve_ivp`，会调步长、刚性方法与结果检查。
4. 3D 几何：旋转、投影、反射、距离、相交。
5. 约束优化：`minimize`、`LinearConstraint`、`differential_evolution`。
6. 结果验证：单位、量级、守恒量、边界情形、敏感性。

### P1：A 题重点

1. 一维热传导 PDE 有限差分。
2. 耦合振动 ODE 与能量/功率计算。
3. 阿基米德螺线与刚体链接运动学。
4. 光线追踪、遮挡与蒙特卡洛效率估计。
5. 物理参数反演。

### P1：B 题重点

1. 动态规划与资源约束路径。
2. 离散事件调度与 CP-SAT/MILP。
3. 抽样检验、期望成本决策树。
4. 光谱/干涉模型与非线性拟合。
5. 布线、覆盖、重叠率等几何优化。

### P2：提升论文上限

1. 多目标优化与 Pareto 分析。
2. 代理模型加速黑箱仿真优化。
3. 鲁棒优化与不确定性量化。
4. 高质量图：几何示意图、误差带、热力图、收敛曲线。
5. 结果可复现模板与实验记录规范。

## 对备赛策略的直接影响

1. **不要把 A/B 当成“物理题/运筹题”二分**。近年两题都在向“机理 + 几何 + 优化”的混合形态靠拢。
2. **三人分工建议**：一人守机理建模与物理方程，一人守优化与离散决策，一人守几何/信号/论文整合。
3. **代码库先行**：至少准备 ODE、PDE、非线性拟合、几何运算、MILP/DP、绘图六个可复用模块。
4. **验证文化比模型华丽更重要**：每年题面都会要求结果文件、精度、可靠性或稳定性，评委也重点看结果是否可信。
