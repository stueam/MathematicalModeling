## 版本对应

两批均为`bayes_tsp_v6_cached_computation`（V6及等价计算缓存），对应论文中的`bayes-fast`策略。已归档的`archived-validation.json`记录40图逐动作复核及其与V6的等价结果；`final-version.json`明确将这两批列为交付版本的留出与压力验证。

40图批次与最终交付版本的缓存模块及实验入口文件哈希有差别，因此不声称当时全部源文件与今天逐字相同。其余已映射的21个文件与迁移清单一致，24组压力验证使用最终缓存模块；当前`shared.py`另有迁移到vendor的路径调整。本文引用的是已有策略实验，不把当前工作区的单例重跑包装成新的64局实测。历史逐动作大文件未全部归档，本次直接复核的是保存的64条结果记录与既有独立审计。

## 统计与比较

仅使用“组内总时间÷组内总源数”一种平均口径。先核对每局成功数、完成证据、异常状态、五项费用之和及移动距离/5，再汇总。随机40图为216.0097199083秒/源，压力24组为207.4575582596秒/源，两批全部清除且完成确认。

全知者136.5153344221秒/源仅计访问源坐标的最短移动；加每源5秒光学定位与清除后为141.5153344221秒/源。与随机40图的平均任务时间相差74.4943854861秒/源。两批地图没有逐图配对，不将差额解释为同图信息成本或近似最优比；压力地图不与均匀地图直接排名。

运行 `python src/Q3/evidence/paper_results/verify.py` 可复算表格，不依赖目录外的论文文件。需要同时检查正文数值时，在仓库根目录运行 `python src/Q3/evidence/paper_results/verify.py --paper essay/essay.tex`。
