# 代码与论文对应范围

范围依据为仓库 `essay/essay.tex`。论文所用的 Q3、Q4 各自只保留一个决策类，配置中已删除算法切换布尔项。命令行只接受地图、执行预算和输出参数。

| 论文部分 | 代码 | 保留用途 |
| --- | --- | --- |
| 问题二：位置先验、反馈预测、期望覆盖半径 | `Q2/model_core.py` | 保守区域运算、固定 R0 积分、`Design.evaluate` |
| 问题二：数值选点与算例 | `Q2/run.py` | 全局粗网格、局部加密、指定点评估 |
| 问题三：频道状态与贝叶斯更新 | `Q3/bayes_tsp/posterior.py`、`coupling.py` | 固定 R 后验、数量条件化、收/不收信号的半平面约束 |
| 问题三：候选动作与时间评价 | `Q3/bayes_tsp/policy.py` | 补测、试探清除、保守清除和全部剩余任务评分 |
| 问题三：搜索与清除的路线统筹 | `Q3/bayes_tsp/open_routes.py`、`routing.py`、`scheduling.py` | 开放路线 DP/2-opt、滚动候选路线、当前与未来停靠点的观测收益 |
| 问题三：扇区与可移动覆盖站 | `Q3/bayes_tsp/stations.py`、`repair.py`、`policy.py` | 全部顶点覆盖约束下的站点优化与数值可行性修复 |
| 问题三：策略执行与停止 | `Q3/bayes_tsp/policy.py`、`vendor/q3/core.py` | 实际反馈、保守几何、有限网格清除与覆盖后备 |
| 问题四：多点联合排除 | `Q4/q4/coverage.py`、`core.py` | 三点联合负反馈证书与频道状态更新 |
| 问题四：覆盖全域的测点布局 | `Q4/s21_layout.py`、`s21_certificate.json`、`check_s21_certificate.py` | 唯一 S21 布局及整数/几何证书复核 |
| 问题四：贝叶斯更新与行动选择 | `Q4/q4/posterior.py`、`localization.py`、`routing.py`、`policy.py` | 类型/朝向后验、移动补测、联合开放路线、保守后备 |
| 问题三/四：完整任务实验 | 各题 `run.py`、`simulator.py` | 固定论文地图、本地反馈环境和完成结果核验 |
| 问题三/四：实际执行 | 各题 `practice_windows.py`、`start_formal.py`、`formal_session.py`、`vendor/q3/client.py` | 串行协议、同 ID 重试、截止时间、运行日志 |

`shared.py` 和包初始化文件仅负责加载上述依赖。测试文件仅验证保留算法、几何、数值和协议；有限后备步骤属于论文执行算法，已经从旧基线类中提取，不再提供独立基线入口。

本次删除 Q3 的历史策略族、固定/移动覆盖消融、补测/扫描开关、额外路线探测和细积分复核分支；删除 Q4 的基线及其他策略入口、自适应合并分支和 S22 布局比较代码。内部路线审计、演练分析脚本及过期交付清单也已移除。

## 可复核边界

`verify.py` 从显式运行入口遍历本地依赖，测试引用和任意脚本的 `__main__` 标记都不能保活运行模块。同时执行 Ruff、Vulture、单元测试和完整本地运行。算法类已经人工按最终调用链展开并逐项对照论文；静态检查用于发现残留引用，不将“没有告警”等同于数学证明。

Q1 的半平面交、直径与最小覆盖圆算例代码仍在论文原路径 `essay/data/q1_two_cases/`。论文源文件、插图和仓库其他开发目录不在本次 `src` 清理范围内。
