# 碳化硅外延层厚度的双光束和多光束干涉法测量研究

## 摘要

碳化硅是一种新兴的第三代半导体材料，其外延层的厚度对其性能至关重要。而红外干涉法是外延层厚度的一种无损伤测量方法。本文通过分析红外光束的干涉效应，建立了相应的于涉模型和厚度测量模型。采用多种优化方法，在双光束和多光束干涉场景下获得了精确的的外延层厚度值。

针对问题一：构建双光束干涉模型。首先，依据Snell定律修正入射角的影响，推导出外延层内光程差与相位差。接着，利用Fresnel公式计算空气-外延层、外延层-衬底界面的反射系数，引入Cauchy色散模型描述折射率随波长的变化，建立外延层厚度与红外光谱反射率的模型关系。求解时通过傅里叶变换法获取于涉条纹周期并提取振荡周期，得到外延层厚度粗略的初始估计值，最后采用非线性最小二乘法拟合模型参数，为后续厚度反演提供清晰的理论框架。

针对问题二:基于问题一模型，对碳化硅晶圆片在入射角 $1 0 ^ { \circ }$ 和 $1 5 ^ { \circ }$ 的实验数据进行厚度反演。首先对光谱数据进行等间距重采样，裁剪 $1 0 0 0 ~ \mathrm { c m ^ { - 1 } }$ 以下低波数干扰区。然后对光谱利用非对称最小二乘法(AsLS)去趋势与 Savitzky Golay 平滑去噪。随后通过滑窗傅里叶变换筛选高信噪比有效频段 $[ 2 5 0 0 , 3 7 0 0 ] \mathrm { c m } ^ { - 1 }$ ，采用双角联合拟合策略共享厚度与色散参数，引入波数刻度和入射角微偏差校准量，利用随机梯度下降法进行全参拟合，最终得到SiC外延层厚度约7.604μm，残差均方根误差低于 $\mathbf { 1 . 1 4 \times 1 0 ^ { - 3 } }$ 。此外，本文从残差统计特性、正态性检验、角度一致性、系统敏感性等多个维度对模型进行了可靠性检验，确保了模型的准确性与稳健性。

针对问题三：构建Airy多光束干涉+Cauchy色散模型。首先对两角度光谱进行等距重采样与轻量多项式去基线，随后采用滑窗FFT提取主频f\*与信噪比，并据此选择有效带宽 $[ 1 1 7 0 , 2 1 7 0 ] \mathrm { c m } ^ { - 1 }$ 作为厚度反演的工作区间。结合相干长度判据与界面反射率锐度系数F的分析得到多光束相干条件，并据此判定出硅晶圆片存在显著多光束干涉，而碳化硅样品因SiC/Si界面反射率仅约0.016，高阶反射贡献可忽略，沿用两光束模型即可。基于此，我们对硅样品建立Airy型多光束干涉+Cauchy色散模型，在两角度数据上联合最小二乘全参拟合，残差主峰位置复现实验条纹、幅值整体小于0.02，最终得到硅晶圆片厚度约3.814μm。

关键字:外延层厚度测量 傅里叶变换 多光束于涉 Cauchy 色散模型 Airy公式

## 一、问题重述

## 1.1问题背景

碳化硅（(SiC）作为新一代半导体材料，因其宽禁带、高热导率和高击穿场强等特性，被广泛应用于电力电子、轨道交通、新能源汽车等领域。外延工艺是碳化硅晶圆制造的关键环节，而外延层的厚度直接影响器件的导通电阻、击穿电压和整体性能。因此，如何准确测定外延层厚度，不仅是科研中的重要课题，也是产业界在质量控制与性能优化中的迫切需求。

与此同时，硅材料作为传统半导体的基础，在电子器件制造中依然占据着重要地位。对硅及碳化硅材料外延层的厚度测量与比较研究，不仅能够为半导体产业的发展提供参考数据，也有助于推动材料检测技术的进一步完善。

## 1.2 问题提出

基于上述背景，本文建立数学模型解决下列问题：

问题一在仅考虑外延层与衬底界面分别发生一次反射与投射所形成的两光束干涉情况下，构建外延层厚度的数学模型。

问题二利用问题一所建立的模型，对碳化硅晶圆片在入射角为 $1 0 ^ { \circ }$ 和 $1 5 ^ { \circ }$ 时的实验数据进行厚度反演，并对结果的准确性与可靠性进行评估。

问题三分析多光束干涉产生的条件和其对厚度测定结果的影响，判断硅晶圆片的实验数据是否存在多光束干涉，并在必要时建立相应的模型与算法进行厚度求解。同时，若碳化硅数据中存在类似影响，提出相应的修正方法并给出校正后的厚度结果。

## 二、问题分析

## 2.1问题一

问题一的核心是建立一个光学干涉模型，用于描述外延层厚度与红外反射光谱之间的关系。入射光在外延层表面和衬底界面分别发生反射，两束光在一定条件下相干叠加，从而形成于涉条纹。条纹的周期和强度不仅依赖于外延层的厚度，还与材料折射率和入射角有关。因此，需要在理想化的“两光束于涉”假设下，构建厚度与波数之间的函数关系。由于折射率随波长和载流子浓度而变化，可引入合适的色散模型加以描述，使得模型更贴近实际情况。通过这一模型，可以为后续的厚度估计和算法设计提供清晰的理论依据。

## 2.2问题二

在已有两光束于涉模型的基础上，问题二的任务是利用实测数据对外延层厚度进行反演计算。已知条件是碳化硅晶圆片在两种入射角下的实测光谱曲线，关键在于如何将模型与实际数据结合，得到可靠的厚度值。

首先，需要对光谱数据进行预处理，包括去除噪声、归一化、选择合适的频段，以确保用于拟合的数据的质量。随后，根据问题一建立的模型，设计合适的算法对参数进行拟合。为了保证结果的稳定性和可信度，可以采用两步法：先通过频域分析获得厚度的初值，再利用非线性优化方法在全频段范围内精细拟合。在此过程中，充分利用入射角 $1 0 ^ { \circ }$ 与 $1 5 ^ { \circ }$ 的两组数据，通过联合拟合与结果对比来验证模型的适用性。最后，结合残差分析与参数灵敏度讨论，对所得厚度结果给出可靠性评估。

## 2.3问题三

问题三在前两问的基础上考虑了多光束干涉的更多情况，要求分析产生多光束干涉的条件以合理选择模型解决相应问题。在建立模型之后，根据硅晶圆片和碳化硅晶圆片的实测光谱曲线，选择合适的模型，得到更精确的效果。

为此，对问题一的模型进行一些修正，将其推广到多光束情形，同时得到必要条件与精度影响。在推导获得多光束模型后，将光谱数据按问题二的流程进行预处理，通过频域分析获取初值，采用非线性优化算法对硅晶圆片用多光束模型进行拟合，从而评价模型的适用性，并给出可靠性评估。对碳化硅晶圆片，在预处理后，利用带通滤波的方法对原图进行优化，消除其他光束的影响，再利用问题二的计算方法得到厚度值。

## 三、模型假设

1. 厚度与面内均匀性：假设外延层厚度d在光斑范围内不随波数/时间变化（面内与时间上均匀稳定)。

2. 衬底折射率平稳：假设在选定带宽内，衬底折射率 $n _ { 2 }$ 近似平稳。SiC样本取 $n _ { 2 } \approx 2 . 6 5$ Si 样本取 $n _ { 2 } \approx 3 . 4 2$

3. 各向同性:假设介质各向同性、界面理想平行，忽略粗糙、楔角影响。

4. 介质吸收率较低：假设介质足够透明，红外光在介质表面发生折射和反射以及在介质中传播时介质对光能的吸收较低可以忽略，反射率与透射率之和为1。

## 五、模型建立与求解

## 5.1问题一模型的建立与求解

## 5.1.1两光束干涉厚度模型的建立

在红外于涉测厚实验中，入射光在空气外延层界面和外延层衬底界面各发生一次反射，两束光在探测端叠加产生干涉条纹。为描述这一现象，我们建立“两光束干涉厚度模型”。

设空气折射率为 $n _ { 0 } = 1$ ，外延层折射率为 $n _ { 1 } ( \lambda )$ ，厚度为 $d$ ，衬底折射率为 $n _ { 2 }$ ，入射角为 $\theta _ { 0 }$ 。根据Snell定律，外延层中的折射角为

$$
n _ { 0 } \sin \theta _ { 0 } = n _ { 1 } ( \lambda ) \sin \theta _ { 1 } ,\tag{1}
$$

其中， $\theta _ { 1 }$ 为外延层中的折射角。

光在外延层内的往返光程差为

$$
\Delta L = 2 n _ { 1 } ( \lambda ) d \cos \theta _ { 1 } ,\tag{2}
$$

对应的相位差为

$$
\delta ( \lambda ) = \frac { 4 \pi n _ { 1 } ( \lambda ) d \cos \theta _ { 1 } } { \lambda } .\tag{3}
$$

![](images/97ab6be4c751b6bb524bc987764a039fb838288915698159da207e3f3bedde1e.jpg)  
图1 两光束干涉模型的光路示意图

利用Fresnel公式，空气-外延层及外延层-衬底的反射系数分别为

$$
r _ { 0 1 } = \frac { n _ { 0 } \cos \theta _ { 0 } - n _ { 1 } ( \lambda ) \cos \theta _ { 1 } } { n _ { 0 } \cos \theta _ { 0 } + n _ { 1 } ( \lambda ) \cos \theta _ { 1 } } ,\tag{4}
$$

$$
r _ { 1 2 } = \frac { n _ { 1 } ( \lambda ) \cos \theta _ { 1 } - n _ { 2 } \cos \theta _ { 2 } } { n _ { 1 } ( \lambda ) \cos \theta _ { 1 } + n _ { 2 } \cos \theta _ { 2 } } ,\tag{5}
$$

其中 $\theta _ { 2 }$ 为在衬底中的折射角。

则总反射率为

$$
R ( \lambda ) = \left| r _ { 0 1 } + r _ { 1 2 } e ^ { i \delta ( \lambda ) } \right| ^ { 2 } .\tag{6}
$$

为刻画色散效应，引入Cauchy模型近似外延层折射率：

$$
n _ { 1 } ( \lambda ) = A + \frac { B } { \lambda ^ { 2 } } ,\tag{7}
$$

其中A,B为待定参数。至此，我们已建立了外延层厚度 $d$ 与红外光谱R(λ)之间的函数关系。

## 5.1.2两光束干涉厚度模型的求解

由于厚度d出现在非线性相位函数中，难以直接解析求解，需要结合实验数据进行数值反演。求解思路如下：

首先由于涉条纹周期与厚度的近似关系

$$
\Delta \left( \frac { 1 } { \lambda } \right) \approx \frac { 1 } { 2 n _ { 1 } d \cos \theta _ { 1 } } ,\tag{8}
$$

通过FFT分析光谱条纹周期，对厚度做出初步估计，得到厚度初值 $d _ { 0 }$ 6

接下来构造目标函数：

$$
J ( d , A , B ) = \sum _ { i } \left( R ^ { \mathrm { o b s } } ( \lambda _ { i } ) - R ( \lambda _ { i } ; d , A , B ) \right) ^ { 2 } ,\tag{9}
$$

其中 $R ^ { \mathrm { o b s } }$ 为实验数据， $R ( \cdot )$ 为理论模型。

下面以 $d _ { 0 }$ 为初值，采用非线性最小二乘法拟合参数(d,A,B)，得到厚度估计 $d ^ { * }$ 。

最后，对不同入射角的两组实验数据进行联合拟合，比较结果的一致性，并通过残差分析验证拟合的合理性。

## 5.2.2基于 Cauchy折射率模型的外延层厚度反演

物理模型与参数化与校准量设两组入射角分别为 $\theta _ { 0 } ^ { ( 1 0 ) } = 1 0 ^ { \circ }$ 与 $\theta _ { 0 } ^ { ( 1 5 ) } = 1 5 ^ { \circ }$ ，对应观测数据为 $\{ ( \bar { \nu } _ { k , i } , R _ { k , i } ^ { \mathrm { o b s } } ) \}$ ，其中 $\tilde { \nu } = 1 / \lambda$ 为波数， $k \in \{ 1 0 , 1 5 \}$ 标识角度。

为消除仪器与几何的系统性微偏差，引入两类校准量：

1. 波数刻度校准 $\varepsilon { : }$ 令真实波数为 $\tilde { \nu } ^ { \mathrm { u e } } = ( 1 + \varepsilon ) \tilde { \nu }$ ，以补偿谱仪刻度的线性误差。

2. 人射角微偏差 $\Delta \theta _ { k }$ :令有效入射角 $\hat { \theta } _ { k } = \theta _ { 0 } ^ { ( k ) } + \Delta \theta _ { k }$ ，以补偿装调误差。考虑上述校准后，两光束模型的理论反射率写为

$$
R _ { \mathrm { m o d e l } } \bigl ( \tilde { \nu } ; d , A , B , \bar { \theta } _ { k } , ( 1 + \varepsilon ) \bigr ) = \mathcal { R } \Bigl ( \lambda - \tilde { \nu } ^ { - 1 } , d , n _ { 1 } ( \lambda ; A , B ) , \tilde { \theta } _ { k } \Bigr ) ,\tag{19}
$$

其中 $\mathcal { R } ( \cdot )$ 由第5.1.1节给出(Fresnel强度反射率 $R _ { 1 } , R _ { 2 }$ 与相位差 $\begin{array} { r } { \delta = \frac { 4 \pi n _ { 1 } d \cos \theta _ { 1 } } { \lambda } } \end{array}$ 的组合式)。

$$
n ( \lambda ) = A + \frac { B } { \lambda ^ { 2 } } ,\tag{20}
$$

其中A,B为待估参数。

由 Snell 定律有 sin $\theta _ { t } = \sin \theta _ { i } / n ( \lambda )$ ，从而 $\cos \theta _ { t } = \sqrt { 1 - \sin ^ { 2 } \theta _ { t } }$

设外延层厚度为d[μm]，薄膜往返相位为

$$
\beta ( \lambda , \theta _ { i } ) = \frac { 2 \pi n ( \lambda ) d \cos \theta _ { t } } { \lambda } .\tag{21}
$$

为了将求解重点放在相位对齐(决定条纹位置、对d最敏感)，我们采用相位优先的反射率模型：

$$
\widehat { R } ( \nu ; \theta _ { i } ) = c _ { \theta } + s _ { \theta } \cos \big ( 2 \beta ( \lambda , \theta _ { i } ) \big ) ,\tag{22}
$$

其中 $C _ { \theta } , s _ { \theta }$ 为不同入射角的幅度与偏置系数。

闭式幅值/基线标定 为抵消探测链路的幅值与基线差异，对每条曲线保留闭式线性标定：给定一组参数 $( d , A , B , \varepsilon , \Delta \theta _ { k } )$ ，先计算理论序列 $y _ { k , i } = R _ { \mathrm { m o d e l } } ( \tilde { \nu } _ { k , i } ( 1 + \varepsilon ) ; d , A , B , \tilde { \theta } _ { k } )$ ，然后用最小二乘闭式解：

$$
a _ { k } = \frac { \mathrm { C o v } ( y _ { k } , R _ { k } ^ { \mathrm { o b s } } ) } { \mathrm { V a r } ( y _ { k } ) } , \qquad b _ { k } = \overline { { R _ { k } ^ { \mathrm { o b s } } } } - a _ { k } \overline { { y _ { k } } } ,\tag{23}
$$

得到校正后的模型输出 $\widehat { R } _ { k , i } = a _ { k } y _ { k , i } + b _ { k }$ 。这种“内环闭式、外环非线性”的结构可减少优化变量，提升稳定性。

双角联合的鲁棒目标函数 直接分别对 $1 0 ^ { \circ }$ 与 $1 5 ^ { \circ }$ 两组数据独立拟合厚度 $d _ { 1 0 }$ 与 $d _ { 1 5 }$ ，再取其平均作为最终结果的方法主要存在以下两大缺陷：

1. 物理一致性不足：外延层厚度d在物理上应为同一常数，而独立拟合时每个角度的色散参数(A,B)可能向不同方向漂移，导致 $d _ { 1 0 } , d _ { 1 5 }$ 不完全可比。

2. 稳健性不足:当某一角度数据在局部波段信噪比较低或受吸收峰干扰时，独立拟合结果容易受到显著偏移，取平均并不能消除该偏差。

相比之下，双角联合拟合在一个统一的目标函数下同时利用两角度的观测数据，共享厚度d与折射率色散参数(A,B)，而仅允许角度校准量 $\Delta \theta _ { k }$ 独立变化。这种方式既保证了厚度的物理唯一性，又利用了两角度在噪声与系统误差上的互补性，从而得到更稳定、可靠的反演结果。

基于上述考虑，我们构造了带有物理先验正则的加权鲁棒最小二乘目标：

$$
\operatorname* { m i n } _ { \substack { d , A , B , s ; ( \Delta \theta _ { k } ) } } \sum _ { k \in \{ 1 0 , 1 5 \} } \sum _ { i } w _ { k , i } \rho \Big ( R _ { k , i } ^ { \mathrm { o b s } } - \widehat R _ { k , i } \Big ) + \eta _ { \xi } \varepsilon ^ { 2 } + \eta _ { \theta } \sum _ { k } ( \Delta \theta _ { k } ) ^ { 2 } + \eta _ { A } ( A - A _ { 0 } ) ^ { 2 } + \eta _ { B } ( B - B _ { 0 } ) ^ { 2 } .
$$

(24)

其中 $w _ { k , i }$ 为数据可信度权重（在吸收段/低信噪比段取较小值)， $\rho ( \cdot )$ 为鲁棒损失函数，本文选用 soft\_11形式; $\left( A _ { 0 } , B _ { 0 } \right)$ 为基于厚度初值 $d _ { 0 }$ 的预拟合结果， $\eta _ { \bullet }$ 为正则权重参数。

这样构造的目标函数兼顾了“内环闭式、外环非线性”的结构:每次迭代中先用闭式解对幅值/基线进行标定，再对 $( d , A , B , \varepsilon , \Delta \theta _ { k } )$ 进行非线性更新，从而在保证收敛稳定性的同时减少了优化变量的数量。s.moeg

## 5.3问题三模型的建立与求解

## 5.3.1多光束干涉的必要条件

在实际实现中，光波可以在外延层界面和衬底界面产生多次反射和透射，从而产生多光束干涉。

设外延层折射率为 $n ( \lambda )$ 、厚度为 $d ,$ 人射角为 $\theta _ { 0 }$ ，层内折射角为 $\theta$ (由斯涅尔定律给出)。记外表面(空气/外延层)与内表面(外延层/衬底)的复反射系数为 $r _ { 1 } , r _ { 2 }$ ，透射系数为 $t _ { 1 } , t _ { 2 }$ 。各级反射光的复振幅为：

$$
{ \bf E } _ { 1 } = { \bf E } _ { 0 } r _ { 1 } , { \bf E } _ { m } = { \bf E } _ { 0 } t _ { 1 } t _ { 1 } ^ { \prime } r _ { 2 } e ^ { i \delta } ( r _ { 1 } ^ { \prime } r _ { 2 } e ^ { - i \delta } ) ^ { m - 2 } , \qquad ( m = 2 , \ldots ) ,\tag{25}
$$

其中相位推移

$$
\delta ( \lambda ) = { \frac { 4 \pi n ( \lambda ) d \cos \theta } { \lambda } } = 4 \pi n ( \sigma ) d \cos \theta \sigma , \qquad ( \sigma = 1 / \lambda ) .\tag{26}
$$

总场为级数之和：

$$
\mathbf { E } _ { r } = \mathbf { E } _ { 0 } r _ { 1 } + \mathbf { E } _ { 0 } t _ { 1 } t _ { 1 } ^ { \prime } r _ { 2 } e ^ { i \delta } \sum _ { m ~ 2 } ^ { \infty } ( r _ { 1 } ^ { \prime } r _ { 2 } e ^ { - i \delta } ) ^ { m - 2 } = \mathbf { E } _ { 0 } \left( r _ { 1 } + { \frac { ( 1 - r _ { 1 } ^ { 2 } ) r _ { 2 } e ^ { - i \delta } } { 1 - r _ { 1 } r _ { 2 } e ^ { - i \delta } } } \right) .\tag{27}
$$

由此得到反射率的Airy型表达式:

$$
R ( \lambda ) = \frac { R _ { 1 } + R _ { 2 } + 2 \sqrt { R _ { 1 } R _ { 2 } } \cos \delta } { 1 + R _ { 1 } R _ { 2 } + 2 \sqrt { R _ { 1 } R _ { 2 } } \cos \delta } , \quad R _ { i } = | r _ { i } | ^ { 2 } ,\tag{28}
$$

该式表明：条纹的相位由 $\delta$ 决定，线形与峰锐度由 $R _ { 1 } , R _ { 2 }$ 决定。

故产生多光束干涉需要满足以下条件：

1. 相干长度条件：光源相干长度 $L _ { c }$ 应大于往返光程差，

$$
L _ { c } \gtrsim 2 n d \cos \theta .\tag{29}
$$

2. 反射率条件:界面反射率不能过小，需保证 $\left| r _ { 1 } r _ { 2 } \right| \ll 1$ 。锐度系数

$$
F = { \frac { 4 { \sqrt { R _ { 1 } R _ { 2 } } } } { ( 1 - { \sqrt { R _ { 1 } R _ { 2 } } } ) ^ { 2 } } }\tag{30}
$$

不应太小。

3. 低吸收条件：外延层吸收系数α较小，使得 $e ^ { - 2 o d \cos \theta }$ 不过小，否则高阶光被显著削弱。

4. 几何与分辨条件：入射光束平行性好，样片楔角小，仪器分辨率优于条纹间隔。

## 5.3.2多光束干涉对厚度计算精度可能的影响

设条纹相位为 $\delta = 4 \pi n d \cos \theta / \lambda$ 6

1. 在理想对称、低损耗条件下，极值近似满足 $\delta = 2 \pi m$ ，条纹间隔

$$
\Delta \sigma \approx { \frac { 1 } { 2 n d \cos \theta } }\tag{31}
$$

与两光束模型一致。因此，多光束干涉并不显著改变条纹的基本周期。

2. 多光束干涉会使条纹更尖锐、对比度增强。如果仍使用两光束正弦模型拟合，会出现模型失配，导致残差具有结构性，从而引入系统偏差。

3. 当 $R _ { 1 } \neq R _ { 2 }$ 或外延层存在吸收时，极值位置发生微小漂移，若用两光束近似会进一步放大厚度计算误差。

4. 在傅里叶域，多光束干涉会引入谐波分量，若忽略处理，可能造成厚度估计偏差。

综上，多光束于涉的存在会影响厚度计算的精度，需要在建模与拟合过程中予以考虑。

## 5.3.4多光束干涉厚度模型的建立

下面，我们建立多光束干涉下的反射率模型。设所有反射光振幅叠加为:

![](images/34561932b487b82c264ec7f6617dea9e00f7c13d6f28ac5242e12c1047d07b08.jpg)  
图28 两光束干涉模型的光路示意图

$$
\mathbf { E } _ { r } = \mathbf { E } _ { 0 } ( r _ { 1 } + t _ { 1 } t _ { 1 } ^ { \prime } r _ { 2 } e ^ { - i \delta } + t _ { 1 } t _ { 1 } ^ { \prime } r _ { 1 } ^ { \prime } r _ { 2 } ^ { 2 } e ^ { - 2 i \delta } + \cdots + t _ { 1 } t _ { 1 } ^ { \prime } r _ { 1 } ^ { m - 2 } r _ { 2 } ^ { m - 1 } e ^ { - ( m - 1 ) i \delta } + \cdots ) ,\tag{36}
$$

其中 $\begin{array} { r } { \delta = \frac { 4 \pi n d \cos \theta } { \lambda } } \end{array}$ 为相位差。

由于 $| r _ { 1 } r _ { 2 } | < 1$ ，上述级数收敛，可视作几何级数求和，得到

$$
\mathbf { E } _ { r } = \mathbf { E } _ { 0 } \left( r _ { 1 } + { \frac { ( 1 - r _ { 1 } ^ { 2 } ) r _ { 2 } e ^ { - i \delta } } { 1 - r _ { 1 } r _ { 2 } e ^ { - i \delta } } } \right) .\tag{37}
$$

由此可得反射率

$$
R = \frac { | \mathbf { E } _ { r } | ^ { 2 } } { | \mathbf { E } _ { 0 } | ^ { 2 } } = \frac { r _ { 1 } ^ { 2 } + r _ { 2 } ^ { 2 } + 2 r _ { 1 } r _ { 2 } \cos \delta } { 1 + r _ { 1 } ^ { 2 } r _ { 2 } ^ { 2 } + 2 r _ { 1 } r _ { 2 } \cos \delta } = \frac { ( r _ { 1 } + r _ { 2 } ) ^ { 2 } - 4 r _ { 1 } r _ { 2 } \sin ^ { 2 } \frac { \delta } { 2 } } { ( 1 + r _ { 1 } r _ { 2 } ) ^ { 2 } - 4 r _ { 1 } r _ { 2 } \sin ^ { 2 } \frac { \delta } { 2 } } .\tag{38}
$$

这就是典型的Airy干涉公式，与Fabry-Pérot干涉腔形式一致。为便于分析，记$R _ { 1 } = r _ { 1 } ^ { 2 } , ~ R _ { 2 } = r _ { 2 } ^ { 2 }$ ，则有

$$
R = \frac { R _ { \mathrm { m a x } } - F \sin ^ { 2 } \frac { \delta } { 2 } } { 1 - F \sin ^ { 2 } \frac { \delta } { 2 } } ,\tag{39}
$$

其中 $F$ 称为锐度系数，这里定义为

$$
F = \frac { 4 \sqrt { R _ { 1 } R _ { 2 } } } { ( 1 + \sqrt { R _ { 1 } R _ { 2 } } ) ^ { 2 } } ,\tag{40}
$$

并有

$$
R _ { \operatorname* { m a x } } = \left( \frac { \sqrt { R _ { 1 } } + \sqrt { R _ { 2 } } } { 1 + \sqrt { R _ { 1 } R _ { 2 } } } \right) ^ { 2 } , \quad R _ { \operatorname* { m i n } } = \left( \frac { \sqrt { R _ { 1 } } - \sqrt { R _ { 2 } } } { 1 - \sqrt { R _ { 1 } R _ { 2 } } } \right) ^ { 2 } .\tag{41}
$$

界面反射率 $R _ { 1 } , R _ { 2 }$ 可由菲涅耳公式计算：

$$
R _ { 1 } = \frac { 1 } { 2 } \left( \frac { \sin ^ { 2 } ( \theta _ { 0 } - \theta _ { 1 } ) } { \sin ^ { 2 } ( \theta _ { 0 } + \theta _ { 1 } ) } + \frac { \tan ^ { 2 } ( \theta _ { 0 } - \theta _ { 1 } ) } { \tan ^ { 2 } ( \theta _ { 0 } + \theta _ { 1 } ) } \right) ,\tag{42}
$$

$$
R _ { 2 } = { \textstyle \frac { 1 } { 2 } } \left( \frac { \sin ^ { 2 } ( \theta _ { 1 } - \theta _ { 2 } ) } { \sin ^ { 2 } ( \theta _ { 1 } + \theta _ { 2 } ) } + \frac { \tan ^ { 2 } ( \theta _ { 1 } - \theta _ { 2 } ) } { \tan ^ { 2 } ( \theta _ { 1 } + \theta _ { 2 } ) } \right) .\tag{43}
$$

由以上推导可见，多光束干涉下的反射率由相位δ控制。条纹极大值与极小值分别对应 $R _ { \mathrm { m a x } }$ 和 $R _ { \mathrm { m i n } }$ ，条纹锐度取决于精细度系数 $F _ { \ell }$ 当 $F$ 较大时，条纹峰值尖锐，厚度分辨率提高，但若仍采用两光束近似拟合，会产生系统偏差；当 $F$ 较小时，多光束效应减弱，可近似为两光束模型。

值得注意的是，厚度 $d$ 与相位 $\delta$ 的关系依然保持周期性：

$$
\delta = { \frac { 4 \pi n d \cos \theta } { \lambda } } \quad \Rightarrow \quad \Delta \sigma \approx { \frac { 1 } { 2 n d \cos \theta } } .\tag{44}
$$

因此，厚度的主周期估算公式与两光束情况一致，但由于Airy线形导致的极值微移和非对称性，若直接使用两光束模型，将低估计算的不确定度，并可能引入1%～2%的系统偏差。为获得高精度厚度，应在建模和拟合中采用Airy型多光束模型。

Step3多光束干涉+Cauchy模型拟合为了同时考虑多光束干涉效应与折射率色散，我们采用基于Cauchy 模型的 Airy 拟合。折射率表示为

$$
n ( \lambda ) = A + { \frac { B } { \lambda ^ { 2 } } } ,\tag{46}
$$

其中A,B为色散参数。

将其代入多光束干涉反射率公式，可得：

$$
R ( \nu ; d , A , B , \varepsilon , \Delta \theta _ { 1 } , \Delta \theta _ { 2 } ) = f ( \nu , d , n ( \lambda ) , \theta + \Delta \theta _ { i } , \varepsilon ) ,\tag{47}
$$

其中 $d$ 为外延层厚度， $\varepsilon$ 表示波数刻度的微小修正， $\Delta \theta _ { 1 } , \Delta \theta _ { 2 }$ 分别为两个实验角度的修正量。

在数值实现上，我们采用最小二乘优化，并在每条曲线上引入线性缩放因子 $a _ { i } , b _ { i }$ 通过残差函数

$$
\mathrm { r e s } = \sum _ { i } \left[ a _ { i } R _ { \mathrm { h a t } } ( { \nu } ; \cdot ) + b _ { i } - R _ { i } ^ { \mathrm { e x p } } ( \nu ) \right] ^ { 2 }\tag{48}
$$

作为目标函数进行迭代求解。

为提高稳健性，我们优化中引入了对 $( A , B , \varepsilon , \Delta \theta )$ 的正则化约束，避免参数偏离物理合理区间。

## 六、模型评价

## 6.1 模型优点

1. 物理完备性：双光束干涉厚度计算模型和多光束干涉厚度计算模型均是基于电磁场理论的严格推导，具有很强的适用性。理论原理与逻辑完备，模型拟合精度较高，获得的结果具有很好的可靠性。

2.可移植性：更换相应参量后根据折射率大小选取模型，可用于解决各类等倾干涉的问题，具有较大的适用范围。

3. 厚度估计可参考性大：采用傅里叶分析的方法获取 $\Delta \nu$ ，有效结合了全谱的数据，结果可靠，由此推算得到的厚度足够精确，作为初值进行拟合时能降低成本，增加计算效率。

## 6.2 模型缺点

1. 理论模型实现难度大:模型理论严格导致具有较多参量以及繁杂的表达式，且光谱数据量大，拟合时的计算复杂度较大，运行成本较高，在实用层面可能有所欠缺。而

为了降低优化算法的成本，容易导致拟合时有较强的初值敏感性，且容易陷入局部最优，因此需要设定较好的初始值，并做好残差分析和多参数交叉验证。

2. 未考虑外延层对光的吸收：两模型均假设外延层足够透明，对光能的吸收率较小以至于可以忽略。在本征吸收频率附近时两模型已不再适用，需考虑原子光谱等更加复杂的修正。
