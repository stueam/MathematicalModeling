# B 题第二问：两个独立 Python 方案

已阅读 `../B题.pdf` 第二问及附录 1、2，并参考 `../第二问代码/算法思路1.txt`、`算法思路2.txt` 和原有 C++ 实现。所有新实现和输出均在本目录；旧 C++ 源码已按要求移除。保留旧实现中有用的概率卷积、粗到细搜索等数学思路，重新实现几何和后验计算，未直接封装旧可执行文件。本项目运行不依赖题目 PDF 或旧 C++ 文件。

## 模型区别

| 项目 | `solver1_bayes.py` | `solver2_fixed.py` |
|---|---|---|
| 接收半径 | 同一源的 R 固定但未知；先验 U[1000,1500] | 用户输入同一个固定 R0 |
| 首次观测后位置权重 | 面积 × P(R≥d1) | 仅按实际有效面积 |
| 第二示向观测 | 观测到一个角度档，严格按整档更新 | 连续示向度，角度档用于数值积分 |
| 定位区域 | 至少 95% 离散后验质量的单元区域，可配置 | 完整几何可行区域 |
| 主目标 J | 期望最小包围圆半径，米 | 期望区域直径，米 |

题目只给出了接收半径和角误差的范围，没有给出概率分布，也没有给出第二问具体的 S1、θ1、R0。面积均匀先验、均匀测角误差，以及不同地点误差条件独立，都是本项目的建模假设。固定 R0 是方案二额外的条件假设，不能当作原题已经告知的真值。两个方案的 J 含义不同，不能直接比较数值判断谁更好。

同地点电磁干扰固定。因此 S2=S1 时读数确定为 θ1、区域保持不变；不抽取新误差。不同地点的误差独立是假设，不意味着题目保证了任意相邻两点的误差独立。

## 方案一：R 的联合后验及解析边际化

令 s(d)=clip[(Rmax−max(Rmin,d))/(Rmax−Rmin),0,1]。首次正常示向度后，单元面积为 A_j、内部求积点距离为 d1_j：

```
w_j ∝ A_j s(d1_j)
R | G_j, O1 ~ Uniform[max(Rmin,d1_j), Rmax]
q_j = P(R ≥ d2_j | G_j,O1) = s(max(d1_j,d2_j)) / s(d1_j)
```

这相当于在离散位置单元上保存 R 的条件分布，对连续 R 精确积分，避免建立三维大网格。第二次没有重新抽 R，也没有使用未经首次观测更新的半径先验。

对 near、no_signal、角度档 k，未归一化后验分别为：

```
w_j 1[d2_j ≤ 5]
w_j 1[d2_j > 5] (1−q_j)
w_j 1[d2_j > 5] q_j alpha_jk
```

它们的总质量就是预测反馈概率。方向反馈下 R 的条件下界增加到 max(Rmin,d1,d2)；无信号反馈下上界降为 min(Rmax,d2)。`first_posterior.csv` 保存首次位置权重和条件 R 区间。

按每个反馈下单元后验质量/实际支持面积排序，累计到 `credible_mass`（默认 .95），取所选完整裁剪单元的并集，由 GEOS 计算其最小包围圆半径。不是把直径除以二，也不是只覆盖单元中心。方向档支持为 θ中心±(ε+半档宽)，near 支持裁剪到 5m 圆，no_signal 支持还要求 d2>Rmin、d2>d1。未截断任何正概率分支。

这是一种可复现的单元近似可信区域：单元内部后验密度用求积近似，覆盖率针对离散后验；不声称得到连续后验精确的 95% HPD 区域。方案一固定使用配置的位置单元，`adaptive_refinement` 只作用于方案二的概率积分。方案一应通过增加 `radial_bins`、`angular_bins` 检查精度。

## 方案二：固定半径下的完整区域直径

```
P1 = Ω ∩ W(S1,θ1,ε) ∩ {5 < d1 ≤ R0}
Pnear = P1 ∩ B(S2,5)
Pnone = P1 \ B(S2,R0)
P2(θ) = P1 ∩ W(S2,θ,ε) ∩ {5 < d2 ≤ R0}
J = pnear D(Pnear) + pnone D(Pnone) + ∫ fdir(θ)D(P2(θ)) dθ
```

先验按面积均匀且首次方向似然在有效楔形内恒定，所以 P1 后验按面积均匀，不加距离衰减权重。near 不是精确点，其区域直径最多 10m；无信号也正常更新区域并计算损失。

Shapely 保留非凸区域、孔洞和多个不连通部件。计算直径时对完整几何的凸包顶点求最远点对（SciPy 向量化）；取凸包不改变直径，但概率计算始终用原裁剪区域面积。严格不等号的开边界以闭包处理，不影响区域直径的上确界或连续面积概率。

扇环单元使用 r² 等间隔、角度等间隔，且逐个与 P1 求交；边界单元按实际保留面积计权，不会因中心落在区域外而丢弃整个单元。圆弧折线之间残留的小片会补回单元集合。使用内部代表点，不假定质心在非凸区域内。单元碰到第二测点距离边界或角度变化较大时，按包围盒四分再与原单元裁剪，子权重按面积守恒。也提供 `source_discretization: "square"` 作为方格版本。

思路二开头要求正方形网格，第三节又详细指定扇环。本版将后面的详细要求作为默认，并保留方格配置，便于对比。

## 角度分档和概率

对真实方位 φ，测角误差 U[−ε,ε]，某档 B_k 的概率因子为：

```
alpha_jk = length(B_k ∩ [φ_j−ε,φ_j+ε] on circle) / (2ε)
```

使用展开区间加模索引处理 0°/360°，仅累加每个点有贡献的少量角度档。不能将“与中心示向度的误差楔形重叠的面积比”直接当作角度档概率，否则相邻重叠楔形会重复计数。

方案二先用自适应面积求积得到各档相对概率，再用几何面积直接计算 near、no_signal 和 direction 三类总质量，并将方向档概率校准到几何方向总质量。这是一个有限网格的积分改进，避免粗网格漏掉 5m 小圆；校准量记录在 `field.csv` 的 `direction_mass_correction`，加密后应减小。若方向区域有面积但未被任何代表点命中，会在该区域重新求积。不是将 direction 无条件归一化为 1。

方案二默认用 Σ p_k D(P2(θ_k)) 近似连续角度积分。正概率档若中心不在可达角度支持内，会在该档实际支持区域构造有效的档内角度，再计算直径，次数记录在 CSV。此补救也是求积近似，应缩小档宽检验，绝不把正概率空分支损失记为零。

方案一按整档的似然更新；方案二按档代表角近似连续观测积分。两者没有混用后验定义。

## 精度与搜索参数

| 配置 | 含义 |
|---|---|
| `radial_bins` / `angular_bins` | 第一可行区域的径向/角向单元数 |
| `source_discretization` | `polar` 默认；或 `square` |
| `source_grid_step` | 方格模式的格长，米 |
| `adaptive_refinement` / `max_refinement_level` | 方案二局部四分开关及最大层数 |
| `arc_tolerance_m` | 圆弧内接折线最大弓高，米；5m 圆另限制到 .001m |
| `angle_bin_width_deg` | 第二示向度积分档宽，必须整除 360，与 angular_bins 不同 |
| `candidate_grid_step` / `refine_levels` | 粗网格间距及加密层数，每层间距减半 |
| `refine_keep` | 每层保留的空间分离的低目标值种子数 |
| `search_domain` | `source_disk`、`extended_disk`、`rectangle` |
| `rectangle` | `[xmin,ymin,xmax,ymax]`，仅矩形模式使用 |
| `near_optimal_relative_tolerance` | 默认 .05，阈值为 1.05 Jmin |
| `zero_objective_threshold_m` | Jmin 接近零的判断阈值 |
| `near_optimal_absolute_tolerance_m` | 仅 Jmin 接近零时，改用 Jmin 加绝对容差 |

extended_disk 半径为 L+R0（方案二）或 L+Rmax（方案一）。默认只在 Ω 内选点，题目并未把机器狗限制在 Ω 内。程序报告的最优值是指定搜索域和实际采样点下的数值最小值，不是允许平面上的全局最优证明。

粗网格后每层从所有已评估点挑选多个相隔至少上一层步长的低 J 种子，各自局部加密，避免只跟踪第一个局部极小值。近优输出是离散近优候选集合；红圈图示并未证明圈间每一点都近优。若需要更连续的区域边界，应减小候选步长并提高加密层数。没有额外接收率约束。

位置单元、角度积分、圆弧折线和候选网格是四种不同的近似。`arc_tolerance_m` 约束单条圆弧误差，不是整个 J 的严格误差上界，几乎相切的集合交可能放大误差。径向、角向、档宽、圆弧均有独立加密实验，结果写入 `results/validation/convergence.csv`；不能根据一次演示就声称达到某个严格精度。

## 输出与验证

每个方案的结果目录包含：

- `summary.json`：完整有效输入、最优点、J、三类概率、耗时、分辨率与诊断。
- `field.csv`：所有候选点；`near_optimal.csv`：近优候选点。
- `bearing_bins.csv`：完整圆周各档无条件概率和对应损失；方案二另保存实际使用的档内代表角（可能因支持边界回退而不同于档中心）。方案一该列仅表示档中心。零概率档损失列占位为 0，不表示该角度可达。
- `first_posterior.csv`：首次位置后验，方案一还包括条件 R 区间。
- `regions.geojson`、`cells.geojson`：完整几何区域及实际裁剪单元，坐标为本地米制平面，不是经纬度。
- 五张 PNG：第一可行区域及划分、首次后验、J 场及近优点、角度概率、代表性反馈区域。

`validate.py` 覆盖圆周概率与独立慢算法对照、三类反馈边界、同点不变、空区域、非凸多部件、near 的无交/部分交/覆盖/相切、固定半径均匀面积密度、联合 R 条件化和概率归一化。

`--numerical` 用真实圆域/扇环的面积均匀拒绝采样以及独立测角误差抽样，每种模型在三个测点各模拟 60000 次，核对包含 near 和 no_signal 的预测概率。方案一从联合先验拒绝采样得到首次后验，并沿用同一个 R；方案二始终固定 R0。这些是模型内自检，没有执行官方模拟器测试。

加 `--with-search` 会在径向×2、角向×2、观测档宽减半、圆弧误差减半时各自重新搜索，记录 J 和最佳点变化。验证报告保留实际执行的结果。Python 版本已实际跑通两套演示；是否需要 C++ 由进一步扩大搜索和精度后的耗时决定。

## 本次实际演示结果

| 方案 | 搜索候选数 | 最佳采样点 S2（米） | J（米） | 含绘图耗时 |
|---|---:|---|---:|---:|
| 贝叶斯 | 110 | (900, 600) | 25.2913，可信区域包围圆半径的期望 | 约 36 秒 |
| 固定 R0 | 112 | (900, 450) | 45.5851，完整区域直径的期望 | 约 5 秒 |

两者最细候选间距均为 150m；分别保留 8 个、11 个近优采样点。概率归一化最大误差约为 1e−14 和 2e−16。上述速度足以运行当前规模，因此没有增加 C++ 重写版本。

9 项基础验证通过。独立蒙特卡洛共检查两种模型、每种三个测点，每点 60000 次。它检验的是模型内概率计算，不提供官方模拟器有效性的证明。

方案二的径向、角向、角度档、圆弧独立加密中，最佳采样点保持 (900,450)，Jmin 的最大变化约 .0145m。方案一对角度分档和可信区域离散更敏感：将角度档从 .5° 减到 .25° 后，Jmin 从 25.2913m 变为 24.4816m，最佳采样点变为 (900,−600)。两侧的好测点都在近优区域分析范围内，不能将初始最佳单点称为精确全局最优。若论文需要更精细的最佳坐标，应继续联合加密位置单元与候选网格。
