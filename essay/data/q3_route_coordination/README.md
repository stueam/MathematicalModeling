# Q3 搜索与清除路线统筹示意

运行 `python generate.py`，生成唯一图件 `q3_route_coordination.png`，并更新几何核验结果 `metrics.json`。需要 Python 3.10+、NumPy、SciPy、Matplotlib；中文字体优先 Microsoft YaHei / SimHei。

`case.json` 保存所有构造坐标。三个面板共享起点 O、清除停留点 A/B/C 和待搜索区域 D1/D2：

1. 分别访问 A、U、B、V、C。
2. A 的 997 m 检测圆覆盖 D1，故在 A 扫描相应频道，省去 U。
3. 在继续完整覆盖 D2 的约束下，将 V 移到 V'，缩短 B—V—C 两段路程。

图中路程由绘制的折线坐标直接计算。两个搜索区域均为凸多边形，逐顶点检查位于凸检测圆内即可保证整个区域被覆盖。脚本同时检查搜索区域与清除点均位于半径 1800 m 的源位置圆域内。独立检测站允许位于圆域外。

V' 由 SLSQP 在覆盖约束下求得，仅展示可行的局部测站调整；图中节省路程仅属于这一构造几何，不是实际日志、不作为算法整体性能或全局最优的证据。重绘不调用正式模拟器。
