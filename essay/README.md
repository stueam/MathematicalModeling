# 论文与插图

论文主文件：[essay.tex](essay.tex)。使用XeLaTeX编译。

## 目录结构

```text
essay/
├── README.md
├── essay.tex
└── data/
    └── <图名>/
        ├── generate.py
        ├── <图名>.png
        └── 必要输入数据与辅助代码
```

## 推送要求

1. 根目录只放本README、论文`.tex`文件和`data/`目录。主文件固定命名为`essay.tex`；版本通过Git和下方更新表记录，不再在文件名中追加版本号。
2. 一张独立PNG对应一个图目录。多面板组合图若输出为同一个PNG，视为一张图；左右独立PNG分别建目录。每个目录保存论文实际使用的PNG、`generate.py`和必要数据、辅助模块。
3. 绘图脚本以自身目录定位输入输出，不依赖个人电脑的绝对路径；默认只生成对应的一张PNG。热力图默认读取冻结的CSV/JSON重绘，添加`--recompute`才重算数值，不能将重绘视为重新验证模型。
4. 正式求解代码放在`src/Q2`至`src/Q4`。图目录可以保存独立复现必需的数值模块，但须说明来源，并与论文模型保持一致。
5. 论文统一通过`data/<图目录>/<图片名>.png`引用图片。更新图片时同步更新生成代码和必要数据，并核对图注、参数及正文数值。未实测的结果不得填写，尚未完成的部分保留明确占位。
6. 推送前确认全部图片引用存在，涉及的生成代码可以运行；使用XeLaTeX编译两遍，检查缺图、未定义引用、溢出及修改页面的版式。编译输出放在`essay/`之外。
7. 不推送PDF、aux、log、out、synctex等编译产物，也不推送缓存、压缩包、历史备份、账号信息或接口日志。只提交本次有意修改的文件。
8. 每次推送论文后，在下方表格追加版本、日期、修改人和更新内容；已有记录保留。表格从本次更新开始记录，历史整理提交仍可从Git查看。

## 生成环境与当前例外

绘图采用Python 3.10+及numpy、scipy、shapely>=2、matplotlib。中文字体为Microsoft YaHei/SimHei，跨平台替换字体可能影响版式。Q2热力图数值核心来自`src/Q2`的固定R0版本；Q1的n=10算例默认随机种子20260911、验证次数200。

- `data/q2_annular_grid_v3/`
- `data/q2_reception_clipping_v4/`

后续新增图片应同时提交真实生成代码。原`PUSH_REQUIREMENTS.tex`中的要求已迁入本README，该文件不再保留。
