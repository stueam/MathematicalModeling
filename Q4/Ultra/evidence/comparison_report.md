# 方法114：S21 与原22点布局的配对实验

日期：2026-09-12。结论：S21有小幅改善迹象，作为候选版本保留；目前不替换正式算法或论文中的22点方案。

## 实验设计

- 使用 method114-review 中的方法114快照，默认 probes 策略。复制到本目录的 method114，原算法文件不作修改。
- S21来源：3371879035-lang/shxjm-B-RL，提交 b4af97c4cc6fbec14fcb4dfb76acd56d4753f87c，brl/coverage.py。
- 唯一策略变量为初始测站坐标：22点双环与S21整数坐标。后验、候选动作生成规则、路线调度、反馈更新、停止条件均相同。
- 16组随机地图：seed 800–815，随机源数10–16、随机接收半径1000–1500 m、混合源类型。
- 14组压力地图：uniform、boundary、outward、tangent、cluster、near、backside各两组。分别采用10个全定向源/半径1000 m/极端误差，与16个全定向源/半径1500 m/空间相关误差。每个配置一个种子，不能视作充分覆盖该情形的重复实验。
- 相同地图共享源位置、半径、辐射方向及由种子和坐标确定的固定误差场。策略不知道真实世界。
- 两个进程运行，单场实时时限1200 s；全部远低于触发时限保护的阈值。

## 覆盖核验

外部整数证书3832个单元全部通过，最远支撑点至单元角点距离998.7888916 m。S21坐标逐项沿用证书。

现有 certifies 在按坐标排序后合并多边形，产生约1.29e-26平方米的残片；原始测站顺序合并时，对本模型外包目标域的差集严格为空。实验初始化采用后者，并再次核验整数证书，没有用面积阈值忽略残片。运行中的 certifies、负反馈排除与停止判据未改动。

## 结果

用时均指每场完整任务的虚拟总用时，包含移动、检测、切换和清除。

平均节约172.75 s，其中移动节约133.62 s，检测34.67 s，切换4.77 s，失败清除增加0.30 s。主要收益来自移动，而非单纯减少一次测站访问。

采用本算法同一开放路径求解器，原22点静态路线为17.639 km，S21为17.909 km。S21静态路线较长，但实际任务路程更短，表明必须连同发现、定位、清除与在线调整来评价。静态路线是启发式结果，不是最短路线证明。

随机组配对平均差值（S21减22点）的bootstrap 95%区间为[-261.65,5.50] s；配对t检验p=0.102。压力组区间[-526.18,36.90] s，p=0.149。两组单独都不足以确认稳定改善。合并30组的p约0.036，但随机与人为构造的压力配置属于不同总体，不将合并显著性解释为官方分布上的优势证明。

最明显退步为seed 9108：10个定向源、半径1000 m、聚集分布、极端误差，总用时5732.93→6451.47 s（+12.53%）。最明显改善为seed 9109：16个定向源、半径1500 m、聚集分布、相关误差，2835.67→1726.65 s（-39.11%）。这些单案例仅用于诊断，不能归结为某类场景必然获益或退步。

## 验证及限制

- 30对世界文件逐字节一致；60场全清且完成证实停止条件。
- 重放全部60场动作，除真实时间戳外的反馈和虚拟时间逐条一致；费用分项加总一致。
- 原始未改动 run.py 另跑seed 800，结果5667.853878 s，与对照驱动中的22点结果完全一致。
- 当前重跑与仓库旧 evidence/local_holdout_800_815.json 的历史数字不完全一致；历史环境或版本差异原因未查明。本实验不混用旧数字，全部比较在同一环境重新运行。
- 本地仿真结果，不是官方演练。没有证明21点最少或全局最优。当前样本不足以直接替换正式版本。

## 文件与复现

- compare.py：实验驱动，仅在构造策略时切换布局函数。
- analyze.py：世界文件、费用、全量动作重放、配对统计审计。
- manifest.json：参数、源代码哈希、覆盖核验记录。
- paired.csv：30对逐场数据；comparison.json：配对统计；summary.json：60场原始汇总。
- runs/：完整世界、动作及决策日志。
- s21_certificate.json、check_s21_certificate.py：外部证书与独立整数检查器。

在本目录运行 `python -X utf8 compare.py`，结束后运行 `python -X utf8 analyze.py`。再次运行会覆盖本目录实验输出；如需新实验，先复制整个目录。
