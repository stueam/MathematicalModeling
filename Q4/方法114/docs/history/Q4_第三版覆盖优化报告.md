# Q4 第三版：删除冗余测站与复用实际停靠点

2026-09-11。本文记录第三版阶段结果，彼时默认是 `trim`。最新默认已经是第四版 `probes`，350 s/src 目标、后续双环及测点实验见 [第四版报告](Q4_第四版移动与测点优化报告.md)。本文历史数据与实验失败记录保留。

在独立的 16 张新地图上，`trim` 相比此前官方演练使用的 `mobile`，平均少用 **611.69 虚拟秒、少走 1646.88 m**；16/16 全清并取得完成证书。42 个压力配置中，平均少用 **422.28 秒、少走 998.33 m**；42/42 完成。收益来自实际执行的完整任务，不是固定任务的最优路线下界，也不是只计算成功清除点。

这些是本地结果。新策略这轮没有连接官方模拟器；此前 15 局官方演练的分数仍属于旧 `mobile`。

## 1. 修改了什么

代码位于 [q4/compact.py](q4/compact.py)，继承原 `mobile`，保留原版用于配对。

- **`trim`：每次离开测站时重新检查搜索义务。** 按当前路线绕行距离和待测频道数排序，尝试删除至多四个候选中的一个冗余站；只有对每个未决频道验证完整未来覆盖成功才删除。之后仍进行原来的联合选路和测站移动。
- **`adaptive`：继续复用实际补测和清除位置。** 在真实收到 direction/near 或成功 clear 的停靠点，尝试替换附近单站，或将附近两个站合并到当前位置。重新计算整条剩余路线和扫描成本，并逐频道验证完整覆盖。没有接受的候选同样记录原因。
- **保留实际完成判定。** 假设未来全为阴性的覆盖证明只用于修改计划，不写入真实观测。计划耗尽而真实完成证书尚未成立时，恢复原 49 点方格有限后备，继续执行测量；不按小面积删除残片，不提前退出。
- **保留精确 TSP。** 任务总节点数不超过 16 时，仍用 Held–Karp 动态规划精确求解开放路线；新优化改变需要访问的站点，而不只重排原站点。

删除失败的结果只在当前公开几何、历史阴性测点和计划站点完全相同时缓存；不缓存世界反馈或后续成本。连续原地扫描仍串行完成，不跳过出发时的重要路线决策。

日志新增 `coverage_plan_audit`、`planned_search_stations`、`cover_pruned_stations`、`shared_merged_stations` 和 `cover_exhaustion_fallbacks`。每次删站、合并的预测节省与完整证书结论可以复查。预测扫描费用采用每频道 6 秒的原有代理，实际成绩按真实移动、切频和动作重新计费。

`run.py` 已接入新策略。本地单局默认 `trim`，配对默认 `mobile trim`。演练适配器新增显式 `--policy trim` / `--policy adaptive`，仍须 `--connect` 才连接，演练默认仍为 `mobile`。

## 2. 独立 16 图配对结果

种子 500～515；同图、同源、同固定误差机制，三种策略各运行 16 局。没有按成绩挑选种子，全部纳入平均。

原始记录：[完整批次](results/20260911-212523-962413/)，包含 config、源码 SHA-256、world、actions、decisions 和 summary。

| 策略 | 完整完成 | 平均虚拟耗时 / s | 平均路程 / m | 平均实际运行 / s | 平均测量次数 |
|---|---:|---:|---:|---:|---:|
| 旧 `mobile` | 16/16 | 7434.87 | 24612.15 | 11.88 | 412.19 |
| `trim` | 16/16 | 6823.18 | 22965.26 | 20.05 | 364.00 |
| `adaptive` | 16/16 | 6843.00 | 22751.86 | 29.44 | 374.81 |

`trim` 的 611.69 秒节省中：移动减少 **329.38 秒**，测量减少 **240.94 秒**，切频减少 **41.94 秒**，失败清除反而增加 **0.56 秒**。成功清除工作相同。

`adaptive` 平均少走 **1860.28 m**，节省移动 **372.06 秒**，总虚拟时间减少 **591.87 秒**。与 `trim` 相比多做扫描，因此虽然路程更短，总耗时反而多 19.82 秒，实际计算也更慢。综合本组总耗时和计算成本，默认选择 `trim`，没有把更复杂的分支直接设为默认。

这里的实际耗时是 16 个独立进程并行时的每局墙钟时间，数值库单线程；不是机器人移动时间，也不是单进程独占机器的 CPU 耗时。

## 3. 42 个压力配置

7 种空间场景 × 3 种固定误差机制 × 2 组参数：`N=10, R=1000, 定向数=9` 与 `N=16, R=1500, 定向数=1`。包含边界向外、切向、近点背向、集中分布及极值/相关误差。参数与旧压力测试一致，没有随策略降低难度。

原始记录：[126 次完整配对运行](results/20260911-212702-025329/)。

| 策略 | 完整完成 | 平均虚拟耗时 / s | 平均路程 / m | 平均实际运行 / s |
|---|---:|---:|---:|---:|
| 旧 `mobile` | 42/42 | 6704.01 | 21072.20 | 9.55 |
| `trim` | 42/42 | 6281.73 | 20073.87 | 16.05 |

`trim` 平均省 **422.28 秒、998.33 m**；`adaptive` 平均省 **481.89 秒、872.19 m**。两者仍有取舍，不能宣称合并测站分支在所有指标上优于删站分支。

## 4. 不成功的尝试与退步案例

首先尝试了边长 950 m 的三角网格，保留覆盖整个源域所需的 31 个顶点，完整初始几何证书有效。`sparse` 仅替换网格，`compact` 再加在线删站。

开发集种子 300～307 的 [32 次配对](results/20260911-211945-395244/) 中，`compact` 平均总耗时虽从 7812.13 秒降至 7205.61 秒，但路程从 25973.75 m 增至 26183.68 m；`trim` 降至 24277.28 m。

随后种子 400～415 的 [48 次复核](results/20260911-212239-431835/) 中，旧 `compact` 有一局清完 11/11 后，没有取得完整公开证书就耗尽计划，抛出 `No tasks but completion is not proved`。批次保留 15/16 完成记录，其截断均值不能当作合格成绩。已补上上述恢复有限网格的处理；种子 407 的 [独立重跑](results/20260911-212451-916022/) 完整结束，7501.23 秒、26486.15 m。没有把这一次修复复测冒充原 16 图全部重跑。三角网格仍保留为实验分支，不作推荐。

加入实际停靠点复用后，在开发集 [24 次配对](results/20260911-212428-299551/) 中，`adaptive` 平均比 `mobile` 少用 662.98 秒、少走 1949.28 m；这是开发结果，与第 2 节新种子复核分开报告。

**新策略也不是逐局占优。** 独立 16 图中，`trim` 与 `adaptive` 各有 14 局虚拟耗时更短。种子 504 有 16 个源、仅一个定向源，旧版较早发现满 16 个而结束；新路线继续进行了更多外围搜索。旧版 3549.96 秒，`trim` 5541.18 秒，`adaptive` 5963.90 秒，分别退步 1991.23 秒和 2413.94 秒。当前未知源的发现收益和未来定位绕行仍没有完整进入费用模型；完整覆盖成立不等于发现顺序最优。这是后续继续优化的具体方向。

## 5. 正确性与协议验证

61 项回归检查通过，包括逐步真值包含、边界朝向、后备完成、精确路线、事务/幂等，以及通过本地假服务验证 `mobile` 和 `adaptive` 的串行演练流程和同 ID 重试。没有在这些测试中连接官方服务。

[第一批独立动作审计](results/audit-20260911-212810-711727/) 重放开发集、新 16 图及修复案例，共 **73 局、29532 条动作**：全部完成，计费差 0，未发现错误排除真实源或错误证明源不存在。

本地世界生成器现在允许显式指定定向数为 0 或 N，以覆盖官方演练已出现的纯类型组成；未指定时仍使用原来的混合分布与随机数序列。该改动不更换旧配对场景。

## 6. 使用

在本目录执行：

```bash
python run.py local --policy trim --seed 0

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run.py benchmark \
  --seed 500 --rounds 16 --compare mobile trim adaptive --workers 16

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run.py validate \
  --compare mobile trim adaptive --workers 16

python -m pytest -q
```

本机临时依赖可通过 `PYTHONPATH=/tmp/mathmodel_q4_deps` 使用；测试增加当前目录 `:.`。依赖路径没有写入源码。各实验实际源码版本以本批 config 的 SHA-256 为准，早期三角分支和修复后的实现不能仅凭策略名称视为同版本。
