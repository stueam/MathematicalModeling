## 统计口径

每张图从原点出发、终点自由、到达全部源坐标，纯移动时间为精确最短路程除以5。随机种子20260912，源数等概率取10–16，源在半径1800米圆内独立按面积均匀生成。这是新随机地图模型，不是官方源位置的实测分布。

逐局等权是各局 `T/N` 的平均；汇总口径是 `总T/总N`。给定源数权重 `p_n` 和各源数条件均值 `t_n`，对应估计分别为 `Σp_n t_n` 与 `Σp_n n t_n / Σp_n n`。重加权复用同一批地图，不增加独立样本数。

138.1155–138.3407秒/源是指定模型下逐局等权均值的近似95%蒙特卡洛区间，不是单图范围，也不包含空间模型误差。130.5434–138.2281秒/源是20米访问最优的逐局等权样本平均几何界，不是置信区间；归档下界计算包含0.01米数值余量。到达源坐标的结果不能称为原任务的严格下界。

所有表格只计移动；每源加一次3秒光学精确定位与2秒清除后，152局权重的汇总参照为140.6455秒/源。本文未将历史50轮Bayes任务成绩填为当前版本结果，未开展新的官方测试，也未把非配对地图比较解释为近似比。

## 复核

从仓库根目录运行，仅需Python标准库：

```bash
python Q3/evidence/paper_q3_oracle/verify.py
```

脚本内部按自身位置定位数据。它核对完成状态、总地图/源数，重新计算各类均值与权重，并与正文两表的全部10行数值逐一核对。

如有本地归档的 `worlds_and_exact_routes.npz`，可进一步使用NumPy、SciPy重算全部十万条路线、分组均值、MC标准误、均值近似t区间与几何界：

```bash
python Q3/evidence/paper_q3_oracle/verify.py --routes /path/to/worlds_and_exact_routes.npz --output Q3/evidence/paper_q3_oracle/verification.json
```

[本次数值复核结果](verification.json) 保存输入哈希和原始路线复核结果。22MB的原始NPZ保留在原实验目录，不重复加入仓库；可由[归档程序和参数](../../results/oracle-tsp-mc-20260912-021030-302657/config.json)按种子重建。
