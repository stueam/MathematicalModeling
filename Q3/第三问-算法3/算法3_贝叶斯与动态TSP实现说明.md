## 2. 双层状态：估计负责效率，完整几何负责证据

每频道维护完整历史、保守位置区域、detected/cleared/absent_certified 等状态；概率层另存裁剪位置单元的求积点、面积权重和相容 R 区间。

几何规则沿用算法1已验证模块：

| 反馈 | 保守更新 |
|---|---|
| direction | 与 ±1.0050001° 楔形、1500 m 外包圆相交，并排除5 m内包圆 |
| near | 与5 m外包圆相交，立即原地清除 |
| no_signal | 排除1000 m内包圆 |
| clear失败 | 排除20 m内包圆，频道仍然存在 |
| clear成功 | 标记cleared，按不同频道计数 |

允许区域用外包，排除区域用内包。一次无信号不等于频道不存在；概率质量消失不等于几何区域为空。

退出仅当所有频道 cleared/absent_certified，或已清除16个不同频道。已确认存在16个频道时可省略其余频道的发现任务，但仍要完成这16个频道的实际清除。

## 3. 贝叶斯模型：连续 R 精确积分，位置近似积分

工作先验：位置在1800 m圆内按面积均匀，R在[1000,1500]均匀，频道存在性先独立Bernoulli(0.65)，再条件化原始总数为10～16。不同检测位置的误差暂按独立U[-1°,1°]，同频道同点的误差固定。

这些分布是建模假设，不是题设事实；压力实验另含相关误差与±1°极值误差。

对位置 x，设有效示向点集合为 D，无信号点集合为 Z：

\[
\ell(x)=\max(1000,\max_{s\in D}\|x-s\|),\qquad
u(x)=\min(1500,\min_{s\in Z}\|x-s\|).
\]

则

\[
p(x\mid H,\text{存在})\propto
\mathbf1_{\Omega\text{及其他约束}}(x)\,[u(x)-\ell(x)]_+
\prod_{j\in D}L_j(x),
\]

\[
R\mid x,H\sim U[\ell(x),u(x)].
\]

观测到两位小数角度 θ 时，真实方位为 φ(x)，角度似然为

\[
L(x)=\frac{\operatorname{length}([\theta-0.005,\theta+0.005)\cap[\phi(x)-1,\phi(x)+1])}{2},
\]

在圆周上处理跨0°区间。代码对每次方向观测除以同一常数0.005，位置归一化后不变；未知频道的存在性证据不含方向观测，因此该缩放不影响存在性更新。同点重复反馈不重复乘似然。

### 3.1 位置离散

每次历史改变后，重新取保守区域的最小旋转包围矩形，划分24×24网格，将所有网格单元与完整区域求交。每个正面积裁剪单元的内部代表点用于积分，质量为“实际保留面积×R边际似然×角度似然”。

这避免只在初始粗粒子中筛选导致后续窄区域永远无点。若首次积分无正质量，尝试48×48；仍失败则保留几何并永久进入可靠后备，不把空网格解释成无源。

代表点积分依然可能漏掉单元内小的正似然部分。它不是连续精确后验，也没有已验证的95%频率覆盖保证。14项单元测试中包含首次径向后验与解析积分的16/32分辨率对照，但这不等于所有多次观测后验均已收敛。

### 3.2 未知频道存在性

用面积求积估计 \(L_c=P(H_c\mid c存在)\)，先更新

\[
q_c=\frac{p_0L_c}{1-p_0+p_0L_c}.
\]

再通过有限Bernoulli卷积精确计算满足总数10～16的条件边际概率。这里只对20个频道的计数求和，不采样哪些频道存在。已发现/已清除频道都计入已知原始源数。

## 4. 确定性反馈积分与动作评分

在新点 q，按每个位置单元的条件R区间计算接收概率

\[
P(接收\mid x,H)=\operatorname{clip}\frac{u(x)-\max(\ell(x),\|x-q\|)}{u(x)-\ell(x)}.
\]

near、no_signal 和全部正概率方向档均参加积分。预测方向档默认宽1°，按连续均匀误差与每档区间的重叠长度分配概率，所有反馈概率和为1。预测使用粗档近似；实际返回后的贝叶斯更新使用0.01°观测档。

### 4.1 局部完成耗时代理

令后验均值为 μ，\(p=P(\|X-\mu\|\le20)\)。代码采用

\[
H(q,p_X)=\frac{\|q-\mu\|}{5}+3+2p+11(1-p)
+\frac{E[\mathbf1_{\|X-\mu\|>20}(\|X-\mu\|-18)_+]}5.
\]

含义：走到均值尝试清除，失败后近似再进行一次6秒测量、一次5秒清除及位置修正移动。数字18是留有余量的接近距离，属于启发式参数。

**这是尚未校准的局部耗时代理，不是完整后续模拟、严格上/下界或保证只需一次补测。** 实际失败会更新几何并继续全部剩余工作。测试已经显示它对某些共享动作和路线安排的评价不足。

对测量动作，积分每种反馈后的H；对尝试清除，计入3/5秒和上述失败恢复代理；然后加剩余已知任务路线、其他已知目标的局部处理代理。未来未知源的实际绕行位置没有建模，因此日志 `score_s` 不能当作整局真实剩余时间的精确预测。

不使用“误差米数＋任意λ×时间”的混合量纲目标，也不使用随机rollout补足代理。

## 5. 与指导文件的对应实现

| 指导内容 | 当前实现及差异 |
|---|---|
| 原点批扫1～20 | 扫描必要未知频道；near优先，已确认16源可省略其他频道 |
| 公共第二测点 | 初始比较96个候选点；按秒数代理与其他动作竞争，不强制必须选公共点 |
| 到公共点批测已知频道 | 维护待测批次，每次发送一个合法measure；near先清除再继续批次 |
| 粒子贝叶斯 | 改成确定性裁剪单元积分，R解析边际化，不做随机粒子重采样 |
| 后验均值与误差E | 决策日志保存mean、expected_error_m、最佳离散清除点和清除概率 |
| 最佳清除点 | 在均值、16个高权重点、最多32个分散求积点中搜索20 m覆盖质量最大点；只是有限候选最大值 |
| Pclear≥0.95为LOCATED | 不作为安全证明，也不强制门槛；≥0.2允许进入尝试清除候选，是否执行由耗时代理比较 |
| 只对LOCATED做TSP | 当前所有detected后验代表点都能进入路线，包括尚不精确的位置；减少悬空任务，但会使早期路线不稳定 |
| Open-TSP | 最近邻初始化、cheapest insertion、开放2-opt；实际移动/观测后更新代表位置，删除完成任务 |
| 途中第三测向 | 明确加入沿估计路线、距目标100/150/200 m的候选；不保证只需三次测向 |
| 清除点扫描未知频道 | 在成功清除点按预测发现与覆盖收益筛选，不强制扫完所有低收益频道 |
| 后续发现目标的公共测量 | 优先利用已有停靠点；300～600 m专门公共二测仅用于原点初始阶段，避免反复额外绕行 |
| 最大盲区 | 仅剩未知任务时，按频道剩余区域生成六扇区覆盖点，按“秒/频道覆盖质量”选点；固定七站继续保留 |

当前动态TSP解决的是代表位置的路线子问题，优化该路线不保证实际搜索定位清除总时间下降。

## 6. 完成后备与执行约束

- 单源达到8次方向观测、首次发现后12次测量或6次清除失败时，使用完整保守区域上的20 m方格清除后备。
- 总动作数达到600或实际剩余时间不足30 s，永久进入可靠完成策略，避免无穷附加信息动作。
- 概率层异常同样进入可靠完成策略，不修改概率以伪造确定结论。
- 1200 m环与原点的最坏最近测站距离968.902 m，低于1000 m；内包圆/外包目标区域采用额外数值余量。
- “有限完成”是几何和动作数量的有限性，不自动保证所有合法地图都在20分钟实际时间及100小时虚拟时间内完成；本次仅给出已运行案例的计时结果。
- 所有≥50 m的正常出发都保存候选比较；后备出发记录completion_override，不冒充正常比较。
- 本策略有路线和批次记忆，不应直接放入算法1现有MC后缀缓存键中；当前完全不使用该缓存。

## 7. 下一步有依据的改进方向

已测结果表明当前主要问题不是程序速度。需要用独立数据校准局部恢复代理，分析后验均值移动导致的路线重排，并将未知频道扫描更明确地联系到可删除的未来补盲任务。

可先比较“低不确定度目标进入TSP、其他目标沿路收集观测”，但还需设计稳定的待定位任务处理和完成保障。该改进尚未实现、尚无效果数字。不能从当前失败实验推断“贝叶斯或TSP本身无用”，也不能从方法名推断它们已经优于基线。
