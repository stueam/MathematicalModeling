# 十轮演练复盘与V6本地试验

## 1. 当前结论

V5真实演练十轮按局平均247.66s/源，汇总243.27s/源，和150s/源目标仍有明显差距。本次没有追加官方演练，更没有使用正式测试。所有诊断来自已保存的公开动作/反馈，改动只在本地生成地图上验证。

已实现可运行的测站数值修复、失败后优先补测，以及6/7/8扇区对照。组合候选 `bayes-v6` 在新留出地图500～519上仅改善约0.96%，压力组改善约1.22%，不足以说明接近150s/源。**默认继续保留有十轮演练记录的V5；V6是本地试验候选，没有新版官方成绩。**

## 2. 十轮真实费用分解

所有1287条动作均按其历史顺序重放到CoupledBelief，策略只看到当时已有反馈；1287次选择与原记录一致，没有动作不匹配。没有用后来清除的位置、源总数或模拟器隐藏数据帮助当时的决策。

| 项目 | 十轮合计/s | 总时间占比（约） |
|---|---:|---:|
| 移动 | 21443.23 | 74.07% |
| measure固定费用 | 5770.00 | 19.93% |
| 切频 | 1099.00 | 3.80% |
| 成功清除 | 595.00 | 2.06% |
| 失败清除直接费用 | 42.00 | 0.15% |

总虚拟时间28949.23s。按动作意图归类，十轮前往扫描任务约41.63km，定位/清除相关移动约65.59km；这些是实际移动分类，不是可以直接删掉的冗余路程。

最后一次成功清除之后，平均只剩43.53虚拟秒、127.64m移动，6/10局没有尾部额外费用。此前V3明显的末尾折返已不是这批V5案例的主要瓶颈，不能继续把全部注意力放在末尾。

1154次测量中，958次执行时频道尚未发现，196次用于已知源定位。事后确认无源的频道共测651次，消耗3886s（含切频）。这些无源证据仍必须取得，不能以事后知道频道为空为由删掉。未发现同频道同一精确坐标的重复测量。

## 3. 找到的明确数值问题：可移动测站大量被拒绝

十轮重放实际调用站点优化3654次，优化器均报告成功；仅583次改善被接受。另有2538次本可缩短静态相邻路段的候选，因约10^-12～10^-6m的约束超限而被拒绝，均属于小于10^-5m的数值残差。

例：第一局公开历史中出现预计缩短118.29m的候选，约束余量却为−1.14×10^-12m；另有约101.32m的候选，余量为−4.62×10^-6m。V5的严格验证保障了覆盖，但直接丢弃整个候选浪费了有用的优化结果。

回放中测试了可行回缩：从原合法点q0向提议点q1做凸组合，二分寻找满足全部原约束的点，再严格检查。**不放宽997m覆盖阈值，不直接接受越界点。** 2538次都能保留严格可行且改善静态路段的点。

这些优化问题会跨决策重复出现，不能把2538次或每次静态节省相加当作任务成绩。修复后走到不同地点，会获得不同反馈，因此官方历史只能证明问题存在及修复的局部可行性，不能直接算出新策略的官方时间。

日志中只保存到最终路线决策的优化调用为2264次、接受388次；它少于回放的完整调用数，因为有些路线计算最后被原地共享测量打断。这两个分母不混用。

## 4. 失败恢复估计需要校准

第9轮 `778K-UEM5-Y4J4-QKT4` 共9次失败clear，其中频道16占5次。前几次预测成功概率约为20.4%、23.1%、25.8%、35.0%，后续仍反复尝试clear，期间出现37m、74m、112m等移动。

全局失败clear直接费用只有42s，不是最大分项；但这种反复猜点会增加移动。不能把失败代价只理解为3s，也不能把“失败后一次补测即可解决”的代理当作已经校准的事实。

实验恢复规则：自上次方向观测后出现clear失败时，优先选择有交会角的新测量，默认估计交角正弦≥0.15；如果有几何保证清除或进入有限网格后备，继续允许clear。所有未清除目标及低概率区域仍保留。

## 7. 下一阶段的优先级

1. 继续处理定位/清除之间的整体移动：这部分实际占65.59km，不能只改善几段扫描站边。
2. 为局部完成时间代理做独立校准，尤其单次方向、长条区域、首次clear失败后的分支。单靠硬门槛只减少失败次数，不一定省总时间。
3. 研究按实际剩余几何自适应合并/拆分覆盖任务，而不是固定7扇区或一刀切改6扇区。所有频道的完整无源证据必须保留。
4. 若有150s/源方案的动作日志或源码，可在相同源数范围、计费、全清与无源证明要求下直接对照，定位其真正节省的操作。现阶段没有这份对照数据，不能确认双方成绩可直接比较。

当前官方按局均值247.66距离150仍很远。已经确认并修复局部问题，但本地增益只有约1%，不能包装成已经追上目标。
