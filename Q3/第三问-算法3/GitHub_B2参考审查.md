## 1. 先区分三个名称

`solver.build_strategy` 中：

- `b2`：早期 `JointStrategy` 联合路线基线。
- `latest`：`PeripheralProposal → FlexibleB3`，包含可移动扫描站、扇区复用、固定R约束等；是该目录默认。
- `q2`：在latest上加入最小包围圆和有限候选期望时间补测，是可选增强。

以下主要参考latest与q2。它们的开发集及新种子成绩不能直接和我们不同地图上的结果排名。

## 2. 最有价值：把扫描站从固定点改成可行区域

`flexible_b3.py::adjust` 用SLSQP最小化

\[
\|q-p_{prev}\|+\|q-p_{next}\|,
\]

同时约束q到当前扇区四个径向/角向角点的距离≤999.5m，并检查方向条件。每次调整后再次优化开放访问顺序，默认做两轮。

这与只做TSP有本质区别：TSP只能重排既定点，它还可以把点移到更顺路的位置。我们V4已把搜索与清除放到同一条路线，但其中专门测站仍主要来自固定骨架；动态点主要用于补盲阶段，尚未沿混合路线连续优化。因此这是最值得下一轮尝试的增量。

在我们的几何内核中应针对每站承担的**完整保守区域**A约束，而不直接套用四角点结论：

\[
q\in\bigcap_{v\in vertices(conv(A))}B(v,1000-\epsilon).
\]

对外包凸包的全部顶点满足距离约束，可覆盖整个A。优化器失败、越界或未改善前后路程时，保留原有合法测点。该连续站点优化尚未接入当前V4，不宣称已有收益。

## 3. 同样关键：清除点替代整块搜索任务

`flexible_b3.py::execute_task` 只有在当前清除点能够覆盖整个待测扇区时，才原地扫描并删除对应扇区任务。不是每个清除点都无条件重复扫描全部未知频道。

我们的V4依靠清除后实际扫描兑现预测覆盖，已明显降低移动，但新留出集平均measure从V3的122.05增至196.30。B2的“替代一个完整待测任务再扫描”提供了进一步压缩冗余操作的方向：

1. 给待搜索区域分配明确的测量任务及负责频道。
2. 当前清除点能承担某个任务时，比较省掉测站的移动收益和扫描开销。
3. 实际扫描结束后才删除已完成的任务。
4. 任务区域仍按频道维护；在这里扫频道1不代表扫过频道2。

需要验证它是否因减少部分覆盖观测而增加末尾路程。不能直接把V4的扫描关掉，却继续在规划中假设这些覆盖已经完成。

## 4. 固定R带来的额外半平面约束

`radius_coupling.py` 利用同一源R固定：在a收到信号，在b无信号，则真实源x满足

\[
\|x-a\|\le R<\|x-b\|,
\]

所以

\[
2(b-a)^Tx < \|b\|^2-\|a\|^2.
\]

这是线性半平面，可以对保守位置区域做进一步裁剪。实现时使用保守的闭半平面外包并留数值余量。

例：a=(0,0)，b=(1000,1000)，得到x+y≤1000的外包约束。某些位置虽然位于b的1000m圆外，却比b更远离a；它们不能同时解释“a有信号、b无信号”，应被排除。

我们已经在贝叶斯权重中用 `[Rlo,Rhi]` 排除了这类不相容位置，但公共保守几何还主要使用楔形、1500m允许圆和1000m排除圆。将这类约束加入**算法三专用的几何层**，可能同时缩小保证清除区域、改善预测清除点的覆盖能力，并减少求积无效区域。需先验证舍入、相等边界和退化情况，避免影响其他算法共用内核。

这项耦合只适用于本题全向源条件；定向源无信号可能来自发射角度，不能直接照搬。

## 5. Q2期望选点：可借鉴入口和候选，不应混用后验

`q2_lookahead.py` 把选点集中在不超过约13个候选：原规则点、当前位置、圆心、长轴法向两侧10/30/60/120m、沿接近方向的点。按预计移动、检测、清除和恢复时间评分。

值得借鉴的是：

- 将候选分成原地、沿路、横向三类，保留原动作进入精评。
- 少量粗评后只精评前几名，控制确定性求积开销。
- 用预测完整区域的包围圆补充概率清除评分，检查恢复代价是否过于乐观。

边界也要保留：

- 它要求所评局部候选对整个P都能保证999m内接收，所以其局部评分令无信号概率为0；我们允许非保证接收动作，必须继续计入无信号分支。
- 它用当前多边形内面积均匀作评分分布，不是我们对未知R解析边际化后的联合后验。
- 它的位置积分采用固定种子的Sobol准蒙特卡洛点；算法三可保留现有确定性裁剪网格，只借鉴候选和分级积分结构。
- 其剩余代价也近似一次额外补测与2r绕行，不是精确最优价值函数。

该仓库报告的140个新种子场景中，latest→q2平均每源时间239.21→235.74s，约改善1.45%；其中98局更快、42局更慢。这支持其局部选点有小幅收益，不支持“换用Q2就大幅解决整体路线问题”。单独更换最小包围圆的均值收益接近零。

## 6. 不宜直接复制的设置

- `PeripheralProposal` 在原点全频扫描零发现时，使用1750m环上的射线交点作外围提议。这是空间先验启发式，不是源确实位于1750m的证据；我们已有贝叶斯R/位置更新，不应强行把分布压到该环上。
- 7扇区、两轮站点调整、trial=80m、lateral=30m、share_range=1000m等都是其开发配置，不是题设最优常数。
- 1m测点间隔不能证明误差独立；我们当前20m重复测量筛选同样只是避免低价值重复，不能把间隔本身当作独立性保证。

## 7. 对当前工作的结论

本轮V4的联合路线与清除点扫描改动，在查看B2之前已经实现并完成新留出验证，效果见 [V4移动优化报告](算法3_V4联合路线与移动优化报告.md)。B2中联合调度的方向与这些实测结果一致。

下一轮最值得按单项对照验证的是：**可移动覆盖测站 → 按完整搜索任务选择性复用清除点 → 固定R半平面收紧**。本次只完成B2审查，没有将未经配对验证的新设置塞入已经冻结验证的V4默认配置。
