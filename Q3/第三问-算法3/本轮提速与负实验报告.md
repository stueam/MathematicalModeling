# 本轮提速与负实验报告

2026-09-11。本轮从已恢复的V5/V6出发，只运行本地模拟，没有连接演练或正式测试。**没有达到170虚拟秒/源；目前的任务成绩改进只有约1%，主要确定收益是减少重复计算。**

## 交付改动

默认入口改为`bayes-fast`，组合已有V6的测站数值修复、失败清除后补测和本轮等价计算缓存。原`bayes-sector`及`bayes-v6`保留；`bayes-sector-fast`可在保留V5动作的情况下只加速计算。

1. 开放TSP的2-opt/重插入候选直接复用预计算边长。原来每个候选都分配坐标数组、求差、重新计算所有边的范数；现在保留原求和顺序、候选顺序和并列判定。
2. 同一决策中，V3参考动作与联合路线菜单重复构建相同频道候选；局部菜单、后续评分直接复用已算出的成本和预测概率。缓存只在一次`choose()`内有效，成功或异常结束均清空；新反馈、接收频道变化和新后验不会沿用旧值。
3. 几何路线缓存仍限制为8张坐标表，每表128个后缀；没有跨世界复用模拟成本。细求积复核和沿路探测继续使用独立评分。
4. 本地多进程显式采用`spawn`，解决当前Python 3.14默认`forkserver`在受限环境绑定套接字失败的问题。HTTP仍串行。`pytest.ini`把默认测试发现限定到`tests/`，防止归档的旧实验测试被误收集。
5. 本地与演练入口支持新策略。演练的界面核验、案例身份核验、同ID重试、截止时间和严格退出条件保留。新版尚未连接官方软件，不能引用旧V5演练成绩作为新版成绩。

## 压力验证

四种空间场景（uniform/boundary/cluster/near）×三种固定误差机制（iid/extreme/correlated）×两种N/R极值，共24组配对。V6和加速版各312/312源全清、24/24证明完成，虚拟费用逐局一致。[48局完整记录](results/20260911-193444-954565/summary.json)。

这验证了等价缓存与现有完成机制在指定场景上的行为，没有把有限样本当成任意地图下的保证。停止条件仍来自完整保守几何或16个不同频道的成功清除，概率质量不足不会证明无源。

交付版本最终81项回归检查通过（12.94秒），包括原几何/协议检查及新增V5/V6逐动作等价、路线并列/子集、起点变化和异常后缓存清理。新默认CLI单局运行也完成15/15源清除。最终配置、环境和代码SHA-256见[交付验证清单](results/20260911-194624-816020/final_validation.json)。

这些结果说明，局部路段变短、固定点TSP代理变好、测点数量增加或信息量增加，都不能直接推出闭环总费用下降。必须看同图完整任务。原始B2参考仍是此前固定提交的[公开实现](https://github.com/stueam/MathematicalModeling/tree/02d2cd36455475ea0be72235b5e147bc2c19a818/Q3/B2)，本轮没有获得队友版本及同图日志，不对其成绩作推断。

完整模拟实验在同一批基于公开历史自采样的相容世界上，比较原动作及最多三个不同任务的替代动作；每条续演均计入剩余搜索、移动、测量、失败清除和完成证明费用。截断/失败不返回成本，任一条不完整时整批弃用。没有连接HTTP，没有让真实地图坐标进入决策。源总数条件化为10～16，同源R和已测位置示向度保持固定。

前两版使用新建V6续演器；后版补齐动态路线、当前目标、待扫描队列、清除后服务及永久后备状态，并以逐动作回归验证其与原状态V6继续运行一致。修正后仍未获得开发集收益，不能把这项一致性缺口宣称为此前退步的解释。有限候选、有限世界、启发式改道门槛也不保证真实新地图改善。实现、测试及SHA-256已归档在[最后一批源码快照](results/20260911-194235-397079/source_snapshot/)，未加入默认或官方入口。

## 复现

在本目录、安装`requirements.txt`后运行：

```bash
python run.py local --seed 0
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run.py benchmark --seed 900 --rounds 40 --compare bayes-sector bayes-v6 bayes-fast --workers 16
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run.py validate --validation-compare bayes-v6 bayes-fast --workers 16
python -m pytest -q
```

本次环境：Python3.14.6、NumPy2.4.6、SciPy1.18.0、Shapely2.1.2。机器现有临时Shapely可通过`PYTHONPATH=/tmp/mathmodel_q4_deps:.`使用；源码没有硬编码这个路径。每批参数、输入种子、实际代码SHA-256及成功/失败记录保存在各新建结果目录中。
