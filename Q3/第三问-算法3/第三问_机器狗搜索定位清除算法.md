# 问题三：机器狗自动搜索、定位与清除算法设计

## 1. 目标与总体思路

问题三要求机器狗从原点出发，在不知道干扰源具体数量、位置和频道分布的情况下，自动完成全部干扰源的搜索、定位和清除，并尽量降低平均定位清除时间。由于评价指标约为 **200 s/源**，算法设计的关键不是对整个圆域进行高密度覆盖，而是：

> **尽量让一次移动、一次测量同时服务于多个干扰源，并把搜索、定位和清除尽可能合并到同一条运动轨迹中。**

因此采用如下总体框架：

1. 原点批量扫描 1–20 频道，快速发现第一批干扰源；
2. 为多个已发现干扰源联合选择一个“公共第二测点”，一次移动完成多源二次测向；
3. 根据两次测向结果估计各干扰源的位置和定位误差；
4. 对已经可以清除的目标进行开放式最短路径规划；
5. 在前往目标途中补充第三次测向，而不是专门绕路测量；
6. 每次清除后，利用当前清除点继续扫描尚未发现的频道；
7. 新发现的干扰源实时插入当前访问路径；
8. 最后只对剩余搜索盲区进行补测，而不是重新覆盖整个区域。

整个算法可以概括为：

```text
原点批量扫描
    ↓
公共第二测点批量定位
    ↓
生成待清除目标
    ↓
Open-TSP / 动态路径规划
    ↓
途中补测 + 清除
    ↓
清除点继续搜索未知频道
    ↓
新目标动态插入
    ↓
最后补搜索盲区
```

## 2. 第一阶段：原点批量扫描

机器狗初始位于原点，因此首先保持位置不变，依次扫描 1–20 频道。

对于每个频道 \(c\)，记录：

- 是否检测到信号；
- 示向度 \(\theta_c\)；
- 当前测量位置；
- 当前定位状态。

建议为每个频道维护如下状态：

```text
UNKNOWN      尚未发现
DETECTED     已发现但尚未可靠定位
LOCATED      已可靠定位
CLEARED      已清除
ABSENT       已判断该频道不存在干扰源
```

原点扫描的优点是所有频道共用同一个位置，因此没有额外移动代价。即使扫描 20 个频道，固定检测时间在所有干扰源之间均摊后仍然较小。

对于原点检测到的干扰源，将第一次测向结果记为：

\[
z_i^{(1)}=(x_0,y_0,\theta_i^{(1)})
\]

其中 \((x_0,y_0)=(0,0)\)。

---

## 3. 第二阶段：联合选择公共第二测点

### 3.1 为什么不能每个干扰源单独找第二测点

若为每个干扰源分别寻找第二测点，会造成大量重复移动。正确思路是：

> **让多个干扰源共用同一个第二测点。**

假设原点发现了 \(m\) 个频道，对每个候选第二测点 \(P\)，预测在那里进行第二次测向后各干扰源的定位效果。

设第 \(i\) 个干扰源在候选点 \(P\) 上的期望定位误差为 \(E_i(P)\)，则可以定义：

\[
J(P)=\sum_{i=1}^{m}E_i(P)+\lambda \frac{\|P-P_0\|}{v}
\]

其中：

- \(E_i(P)\)：第 \(i\) 个干扰源在该位置测量后的预期定位误差；
- \(\|P-P_0\|/v\)：机器狗移动到该点的时间；
- \(\lambda\)：平衡定位精度与移动时间的权重。

选择：

\[
P^*=\arg\min_P J(P)
\]

然后机器狗只移动一次到 \(P^*\)，再对所有已发现频道进行第二次测量。

### 3.2 候选点如何生成

不需要全平面搜索，可在原点周围选若干半径和角度离散枚举，例如：

\[
r\in\{300,400,500,600\}\text{ m}
\]

\[
\phi\in\{0^\circ,15^\circ,30^\circ,\ldots,345^\circ\}
\]

候选点为：

\[
P=(r\cos\phi,r\sin\phi)
\]

随后对每个候选点计算综合代价即可。

## 4. 定位方法：联合贝叶斯更新

每次测量并不直接认为示向度完全准确，而是视为带误差观测。

对于干扰源 \(i\)，设真实位置为：

\[
X_i=(x_i,y_i)
\]

在测点 \(P_t=(x_t,y_t)\) 得到测向结果 \(\theta_t\)，则真实方向满足：

\[
\theta_t-\delta
\le
\operatorname{atan2}(y_i-y_t,x_i-x_t)
\le
\theta_t+\delta
\]

其中 \(\delta\) 为测向误差上界。

采用粒子法实现时，在目标区域内维护若干候选点：

\[
\{(x_k,y_k,w_k)\}_{k=1}^{N}
\]

每次获得新观测后进行更新：

\[
w_k^{(t+1)}
\propto
w_k^{(t)}
L(z_{t+1}\mid x_k,y_k)
\]

然后归一化：

\[
w_k^{(t+1)}
=
\frac{w_k^{(t+1)}}{\sum_j w_j^{(t+1)}}
\]

位置估计取后验均值：

\[
\hat x_i=\sum_k w_kx_k
\]

\[
\hat y_i=\sum_k w_ky_k
\]

定位误差指标可定义为：

\[
E_i
=
\sum_k
w_k
\sqrt{
(x_k-\hat x_i)^2+
(y_k-\hat y_i)^2
}
\]

该 \(E_i\) 可以直接作为“当前定位是否足够精确”的判断指标。

---

## 5. 判断目标是否可以直接清除

清除半径为 20 m，因此比单纯判断 \(E_i<20\) 更稳妥的方法，是计算：

\[
P_i^{\text{clear}}(q)
=
P(\|X_i-q\|\le 20)
\]

在粒子表示下：

\[
P_i^{\text{clear}}(q)
=
\sum_{\|X_k-q\|\le20}w_k
\]

选择最佳清除点：

\[
q_i^*
=
\arg\max_q
P_i^{\text{clear}}(q)
\]

实际中可直接在后验均值附近搜索。

当：

\[
P_i^{\text{clear}}(q_i^*)\ge \tau
\]

例如 \(\tau=0.95\)，则将该目标加入待清除集合。

---

## 6. 第三次测向：放在清除途中完成

如果经过两次测量后仍不足以保证 20 m 内清除，不应专门为第三次测向绕路。

正确策略是：

> **先按照目标估计位置规划清除路线，在前往该目标的途中进行第三次测量。**

假设机器狗当前位置为 \(A\)，目标估计位置为 \(\hat P_i\)，则在：

\[
A\rightarrow \hat P_i
\]

这条路径上选择一个距离目标约 100–200 m 的位置 \(Q_i\) 作为补测点。

机器狗移动到 \(Q_i\) 后：

1. 对频道 \(i\) 再测一次；
2. 更新其后验分布；
3. 重新计算最终估计位置；
4. 直接前往新的清除点执行 `/clear`。

这样第三次测量几乎不产生额外移动距离，只增加一次检测耗时。

同时，由于补测点已经比较接近目标，即使测向角存在约 \(1^\circ\) 的误差，横向位置误差也较小。例如距离为 200 m 时：

\[
200\tan1^\circ\approx3.5\text{ m}
\]

因此第三次测量可以显著提高最终清除成功率。

## 7. 多目标路径规划：Open-TSP

当多个干扰源已经被定位后，不应按照发现顺序逐个清除，而应一次性规划访问顺序。

设当前机器狗位置为 \(C\)，待清除目标为：

\[
P_1,P_2,\ldots,P_m
\]

由于任务完成后不要求返回原点，因此使用开放式 TSP：

\[
\min_{\pi}
\left[
d(C,P_{\pi_1})
+
\sum_{j=1}^{m-1}
d(P_{\pi_j},P_{\pi_{j+1}})
\right]
\]

可采用：

- 小规模动态规划；
- 最近邻初始化；
- 2-opt 局部优化；
- 新目标动态插入。

实际实现推荐：

```text
最近邻生成初始路径
→ 2-opt 优化
→ 新目标出现后 cheapest insertion
→ 再局部 2-opt
```

这样比每次完整重算 TSP 更快，也更适合在线算法。

## 8. 清除点兼作新的搜索点

这是第三问中降低总时间的关键策略之一。

机器狗每到达一个目标位置并完成清除后，都已经处在一个新的空间位置。此时不应立刻移动，而应利用当前位置扫描尚未发现的频道。

因此，每个清除点同时具有两种作用：

1. 清除已知干扰源；
2. 搜索新的干扰源。

这意味着机器狗原本为了清除目标必须进行的移动，同时承担了区域搜索功能。

对于尚未发现的频道 \(c\)，若在位置 \(P_j\) 检测不到信号，则可以利用最小接收半径进行空间排除。

设目标圆域为 \(D\)，该频道当前可能存在区域为 \(F_c\)，初始化：

\[
F_c=D
\]

如果在位置 \(P_j\) 测不到频道 \(c\)，则排除该点周围最小有效接收半径内的区域：

\[
F_c
\leftarrow
F_c\setminus B(P_j,R_{\min})
\]

其中：

\[
R_{\min}=1000\text{ m}
\]

若最终：

\[
F_c=\varnothing
\]

则说明若该频道存在干扰源，本应至少在某一个测点被检测到，因此可以判定：

\[
\boxed{\text{频道 }c\text{ 不存在干扰源}}
\]

---

## 9. 新目标的动态插入

在某个清除点扫描未知频道时，如果发现新的干扰源，则立即：

1. 记录当前第一次测向结果；
2. 建立该频道的后验位置分布；
3. 在后续运动中寻找第二次测量机会；
4. 一旦定位较稳定，插入当前 Open-TSP 路径。

插入目标 \(P_{\text{new}}\) 时，若当前路径存在边：

\[
A\rightarrow B
\]

则插入额外距离为：

\[
\Delta L
=
d(A,P_{\text{new}})
+
d(P_{\text{new}},B)
-
d(A,B)
\]

遍历所有可插入位置，选择 \(\Delta L\) 最小的位置即可。

这就是 cheapest insertion。

## 10. 最后的搜索盲区处理

经过若干次清除后，大部分区域已经被机器狗的路径和测点间接覆盖。

此时如果仍有部分频道无法判断是否存在，不要重新做全区域覆盖搜索，而只针对尚未排除的区域补测。

定义所有已有搜索点为：

\[
S=\{P_1,P_2,\ldots,P_n\}
\]

对于某个未确定频道，其尚未排除区域为：

\[
F_c
=
D-
\bigcup_j B(P_j,R_{\min})
\]

若 \(F_c\neq\varnothing\)，则选择其中最大的未覆盖区域中心作为下一补测点。

可通过离散网格近似：

\[
P^*
=
\arg\max_{P\in D}
\min_j d(P,P_j)
\]

即选择距离所有已有测点最远的位置。

机器狗只对尚未确定的频道进行测量。

若仍未发现信号，则继续缩小其可行域；若发现，则进入正常定位流程。

## 11. 时间优化原则

总时间大致为：

\[
T=
\frac{L}{v}
+
5N_{\text{measure}}
+
N_{\text{switch}}
+
5N_{\text{clear}}
\]

其中：

- \(L\)：机器狗总移动距离；
- \(v=5\text{ m/s}\)；
- \(N_{\text{measure}}\)：总检测次数；
- \(N_{\text{switch}}\)：频道切换次数；
- \(N_{\text{clear}}\)：成功清除次数。

由于测量和清除通常只需要数秒，而跨越数百米就需要几十甚至上百秒，因此：

> **总移动距离是最主要的优化对象。**

算法应遵循以下原则：

1. 多个干扰源尽量共用检测点；
2. 第三次测向尽量放在清除途中；
3. 清除点同时作为新的搜索点；
4. 新目标优先插入已有路径；
5. 不进行高密度全区域覆盖；
6. 只对最终剩余的搜索盲区进行补测。

## 13. 主循环伪代码

```text
进入模拟器
当前位置 ← (0,0)

# 第一阶段：原点扫描
for channel = 1 ... 20:
    measure(原点, channel)

    if 有信号:
        建立该频道的贝叶斯位置分布
        状态 ← DETECTED

# 第二阶段：选择公共第二测点
P2 ← 根据所有已发现目标联合优化得到

移动到 P2

for 每个 DETECTED 频道:
    measure(P2, channel)
    贝叶斯更新
    计算估计位置与 E

    if 清除成功概率足够高:
        状态 ← LOCATED

# 开始动态清除
while 仍存在未清除目标或未确定频道:

    对所有 LOCATED 目标做 Open-TSP / 2-opt

    选择下一目标 target

    if target 定位还不够精确:
        在前往 target 的途中选择补测点 Q
        measure(Q, target.channel)
        贝叶斯更新
        修正 target.position

    clear(target.position, target.channel)

    if 清除成功:
        target.status ← CLEARED

    # 当前清除点兼作搜索点
    for channel in 尚未发现的频道:
        measure(当前位置, channel)

        if 有信号:
            创建新目标
            状态 ← DETECTED
        else:
            更新该频道的可能存在区域

    # 为新发现目标寻找第二测量机会
    利用当前路线中的后续位置进行补测

    # 新目标加入路径
    对新 LOCATED 目标执行 cheapest insertion
    进行局部 2-opt

    # 如果长时间没有新目标
    if 仅剩未确定频道:
        计算各频道剩余搜索区域

        if 所有剩余区域为空:
            将这些频道标记为 ABSENT
        else:
            前往最大搜索盲区补测

退出模拟器
```

## 14. 最终算法概括

问题三不应建模成“先搜索完整区域，再逐个定位和清除”，而应设计成一个动态闭环：

\[
\boxed{
\text{批量搜索}
\rightarrow
\text{联合定位}
\rightarrow
\text{路径优化}
\rightarrow
\text{途中补测}
\rightarrow
\text{顺路清除}
\rightarrow
\text{清除点再搜索}
}
\]

最重要的三个思想是：

1. **共享测点：** 一个位置尽量同时服务多个干扰源；
2. **搜索与清除融合：** 清除路线本身承担区域搜索功能；
3. **动态路径规划：** 新目标不断插入当前路线，而不是每次重新开始。

最终目标不是使某一次定位最精确，而是使：

\[
\boxed{
\frac{\text{总任务时间}}{\text{成功清除干扰源数量}}
}
\]

尽可能小，并在确保全部干扰源最终被清除的前提下，将平均定位清除时间控制在约 **200 s/源** 或更低。
