# Q2 期望选点接入 B2：实现与本地实验

日期：2026-09-11。基线来自 `origin/main` 的 `bae3e1c`，比较对象为仓库的 `latest` 策略。本文的 B2 指这一版本；不是更早的 `--methods b2`。

结论：140 个新种子场景中，三个版本全部完成，均清除 1820/1820 个源。加入 Q2 期望选点后，平均每源虚拟耗时下降 **1.45%**，主要来自移动距离下降。单独使用最小包围圆基本持平。可以保留为可选增强版本，目前没有替换默认 `latest`。

## 1. 实际改了什么

| 方法名 | 几何覆盖圆 | 补测选点 |
|---|---|---|
| `latest` | 外接矩形中心 + 最远顶点距离 | 原 B2 启发式 |
| `mec` | 最小包围圆 | 原 B2 启发式 |
| `q2` | 最小包围圆 | 在局部补测入口按期望时间近似评分 |

覆盖搜索、频道扫描、共享观测、在线路线算法、阴性观测约束、同源固定半径耦合、尝试清除规则和最终兜底均沿用原框架。圆心变化会间接影响路线和清除点，所以 MEC 几何上更紧不意味着整局一定更快。

`q3_strategy.py` 增加实例方法入口 `region_circle` 和 `select_local_measurement`。默认入口保持原行为。各策略通过同一入口使用几何覆盖圆，不进行全局 monkey patch。`solver.build_strategy(action, 'q2')` 可以独立选择增强算法。

新增文件：

- `q2_geometry.py`：最小包围圆、当前凸多边形的面积求积、预测示向度楔形裁剪。
- `q2_lookahead.py`：候选点、两阶段期望评分、MEC/Q2 策略和规划日志。
- `tests/test_q2.py`：几何、概率、边界、重复测点测试。
- `analyze_q2.py`：配对统计、分场景统计和结果图。

## 2. Q2 的思想如何迁移

对当前频道，使用 B2 已累积全部观测后保存的当前可行多边形 P。对候选位置 s，积分潜在目标位置 G 和测角误差 e，预测返回角度，再对 P 追加对应楔形，计算预测区域的最小包围圆。

候选集合最多 13 个：原启发式点、当前位置、区域圆心、垂直长轴两侧的 10/30/60/120 m 偏移点，以及沿当前接近方向的两个点。重复或不安全候选被过滤。每个被评分点须满足：

`max_{G in P} ||G-s|| <= 999 m`。

因此对任意实际固定半径 R∈[1000,1500]，都保证接收，不引入 R 的概率分布，也不擅自固定 R=1200。Q2 规划分支的 `p_none=0`。原 B2 其他搜索和兜底动作仍可能无信号，并按原规则更新。

候选点和该频道历史测点距离须至少 1 m，避免将同位置固定误差当作新的独立测角信息。如果局部入口无可评分候选或面积退化，则明确退回原启发式，不对零面积区域赋概率。

## 3. 评分的定义与假设

选点评分以秒为单位：

`C(s) = ||s-S||/5 + 5 + I[频道切换] + E[Vhat(P_after, s)]`。

若返回 near，随后原地清除，所以 `Vhat=5 s`。否则令预测区域的最小包围圆为 `(center, r)`：

`Vhat = ||center-s||/5 + 5 + I[r>19.8] * λ * (5 + 2r/5)`。

最后一项表示“尚不能保证清除时，估计再做一次测量，并付出约 2r 的绕行”。默认 λ=1。它是剩余时间的启发式近似，不是经过证明的最优价值函数，也不是时间上下界。实际仍可能需要多次补测。

保证清除看包围圆半径 ≤19.8 m，而不是直接用直径≤40 m。near 的期望剩余定位半径按 0 计，含义是可以直接完成清除，不表示目标物理位置已经精确到一点。

规划分布使用：当前保守 P 内按面积均匀，新位置的测角误差按 [-1°,1°] 均匀。它们只是选点评分假设；特别是 P 经保守凸包近似、且真实接收半径未知，不能把它称为精确贝叶斯后验。测试包含固定极端误差和空间平滑误差，检验这一工作假设的部分偏离。

前向求积采用 `sum_j sum_m w_j v_m Vhat(P(theta(G_j,e_m)))`，不把互相重叠的楔形面积比例当作互斥角度档概率。预测角度按题目保留两位小数，几何误差仍取 ±1.005°。near 分支保留清除所需的 5 秒。

预测阶段仅追加新楔形；1500 m 接收上界在候选过滤下已自动满足。没有在每个假想结果中重放全部阴性约束收紧，故预测区域可能偏保守。真正收到反馈后，原 B2 的完整几何更新照常执行。

## 4. 求积与性能

Q2 原来的扇环离散代码没有改动。这一在线版本针对任意当前凸多边形，用内部点作扇形三角剖分：按每个三角形的实际面积选择三角形，再用平方根重心映射在内部均匀采样。使用固定种子的 Sobol 准蒙特卡洛点，不是正方形网格，也不是把不同面积的单元等概率处理。

样本权重为 1/N 是面积均匀采样的求积权重，不表示三角形等概率。相同位置样本供所有候选点共同使用，降低候选比较的积分噪声；加密时保留原样本作为前缀。

默认参数：

| 参数 | 默认值 |
|---|---:|
| 粗评位置样本 | 8 |
| 粗评角误差 Gauss-Legendre 节点 | 2 |
| 精评位置样本 | 32 |
| 精评角误差节点 | 3 |
| 精评候选 | 粗评前 3；必要时额外保留原启发式点 |
| 剩余时间系数 λ | 1 |

有限求积不提供严格误差界，尤其 near 小面积分支可能被少量样本低估。它只影响选点评分，真实 near 判定和清除安全性仍由反馈和保守几何保证。32→64 样本的整局对照是数值敏感性检查，不等价于逐点概率已经严格收敛。

## 5. 140 个新场景的配对实验

种子为 `2026091101`，与旧筛选种子不同。场景生成器与原仓库相同，140 个场景覆盖 10–16 个源、5 类空间分布、1000/1500 m 半径端点及中间值、哈希/固定极端/空间平滑测角误差。每种方法使用完全相同的源、频道、半径和空间误差函数。

参数在这一轮运行前固定，没有根据本轮结果选取更好的配置。新种子并不等于独立的场景机制，也不是官方评测。

“平均每源耗时”是先在每局计算总时间/清除源数，再对各局等权平均，不是所有场景时间与所有源数直接相除。整局时间和每源时间两种汇总的改善百分比因此略有不同。

Q2 有 98 局更快，42 局更慢。按场景配对重采样 10000 次得到的平均每源相对改善 95% bootstrap 区间约为 [0.94%,1.94%]；这是对当前模拟样本的经验描述，不是未知官方分布上的收益保证。

平均每局节约 45.73 秒，移动距离减少 209.33 m，对应移动时间减少 41.87 秒，约占节约量的 91.5%。失败清除次数略升，不能声称所有指标都提升。Q2 总计调用期望选点 824 次，平均每局规划用时 0.380 秒。三个方法本轮均未触发最终网格清除兜底。

## 6. 验证与边界

旧 20 个场景的敏感性结果如下。它们是开发检查，没有用来重新选择 140 新场景实验的参数：

| 配置 | 平均 s/源 | 相对旧场景 latest 的改善 | 完成场景 |
|---|---:|---:|---:|
| 原 latest | 235.9400 | — | 20/20 |
| Q2 默认，32 点，λ=1 | 232.0242 | 1.66% | 20/20 |
| 精评加密为 64 点 | 232.0354 | 1.65% | 20/20 |
| λ=0.5 | 231.8915 | 1.72% | 20/20 |
| λ=2 | 232.5191 | 1.45% | 20/20 |

加密后平均值只变化约 0.011 s/源，但中位数有变化，说明部分场景的动作路径发生了变化。不能仅根据平均值接近宣称每个候选的概率或排名都已收敛。默认保留 32 点、λ=1。

共 9 项 unittest 通过，其中新增 6 项覆盖：

- 最小包围圆与独立枚举 1/2/3 支撑点算法对照，80 组随机小样本；
- 单点、共线、坐标大平移、等边三角形（直径一半不能替代包围圆）；
- 面积求积的内部性、非负权重、归一化、均值精度、嵌套加密和零面积报错；
- near 分支的移动/切换/测量/清除成本和接收半径过滤；
- 角度跨 0°/180°以及 ±1° 极端误差下保留真实目标；
- clear 不切换接收频道，Q2 候选避开已测位置。

原有的接收覆盖、测角与清除边界测试也通过。旧 20 场景上的 latest 结果与改动前一致（235.9399760493 s/源），验证默认入口保留基线行为。

## 7. 复现

在 `Q3/B2` 目录，用该目录已经安装锁定依赖的 `.venv`：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -B -X utf8 benchmark.py --methods latest mec q2 --generate-seed 2026091101 --output outputs/q2_reproduce
.\.venv\Scripts\python.exe -B -X utf8 analyze_q2.py outputs/q2_reproduce
```

需要图时，运行 `analyze_q2.py ... --plot`，要求所用 Python 环境另有 matplotlib；算法及基准测试不依赖 matplotlib。本次作图使用仓库上层已有的 Python 环境。

默认 20 场景上的精度/参数敏感性：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 benchmark.py --methods q2 --q2-fine-power 6 --output outputs/q2_refined
.\.venv\Scripts\python.exe -B -X utf8 benchmark.py --methods q2 --q2-residual-scale 0.5 --output outputs/q2_scale_half
.\.venv\Scripts\python.exe -B -X utf8 benchmark.py --methods q2 --q2-residual-scale 2 --output outputs/q2_scale_double
```

实际接入同原接口：`build_strategy(action_callback, method='q2')`。算法只接收反馈，不读取环境中的源位置、半径、数量或清除真值。测试统计由评估器完成。

## 8. 当前范围

这是 Q2 思想在局部补测中的有限候选、有限求积实现，不是全图全局最优选点，也没有把 Q3 全部频道、路径和未来信息统一求解。首次外环探测、共享测量和超出局部入口的兜底仍由原启发式决定。

本轮结果支持保留 `q2` 作为小幅增强选项。单独换 MEC 没有稳定时间收益。若继续改进，应优先考虑信息价值如何影响共享测量和全局任务顺序；不能将当前 1.45% 的结果外推为任意场景必然改善。
