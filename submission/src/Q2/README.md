# Q2：固定R0的Bayes选点（论文版本）

固定接收半径R0，位置先验按面积均匀，不同测点测角误差假设独立且在±1°均匀分布。反馈包含正常示向、距离过近、无信号，目标为反馈后完整可行区域的期望最小覆盖圆半径J（米）。不使用95%可信区域，也不把直径除以二作为覆盖半径。

数值核心与论文 `essay/data/q2_strategy_heatmaps/model_core.py` 来自同一固定 R0 模型，保留 sector、wedge、metrics、Design 的计算逻辑；图目录保留历史冻结版本，运行包增加输入校验并移除绘图依赖。命令行拒绝非有限坐标和无法生成有效候选网格的步长，汇总中同时输出积分分区误差。统一安装与验证见 [src 说明](../README.md)。

Python 3.10+，在本目录运行：

```sh
python -m pip install -r requirements.txt
# 快速核验论文对称算例的推荐点
python run.py --scenario symmetric --R0 1200 --evaluate 840 495
# 完整候选搜索（耗时明显长于单点评估）
python run.py --scenario symmetric --R0 1200
python run.py --scenario asymmetric --R0 1200
```

对称情形p1=(0,0)、首次示向0°；不对称情形p1=(1200,400)、首次示向65°。目标圆域半径1800m，R0限定1000–1500m。扇环积分80×16、示向度档宽0.125°、全局网格60m、最佳粗网格点附近±90m内按15m加密。对称情况同时加密镜像点。输出CSV/JSON保存在results，可供论文绘图读取；重复运行会覆盖同名结果。

同一点重测沿用原结果。角度档对应多个示向度，几何支持使用其楔形并集。圆弧多边形化与位置代表点积分均为数值近似；推荐点仅是当前网格下的结果，不声称全局最优。
