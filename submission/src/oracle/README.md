# 论文全知者随机地图参照

`run.py` 来自仓库 `Q3/全知TSP蒙特卡洛.py`，改为包内默认路径，默认样本数设为论文的 100000，移除论文未采用的官方源数频率输入。位置生成、随机种子、最短路求解和统计公式沿用原程序。

`open_routes.py` 原样保留十万图批次的求解器快照。`selfcheck.py` 从原 `Q3/全知纯移动基准.py` 仅提取 `exact_route`、`selfcheck` 及其依赖，保留穷举与正多边形解析核验。

从提交包根目录执行 `python src/oracle/run.py --samples 100000 --workers 4`。默认 seed 20260912，源数均匀取 10–16，源位置在半径1800米圆域内按面积均匀生成。每张图使用精确 Held–Karp 开放路线，起点原点、终点自由，不含检测和切频；论文含清除参照需另加 5 秒/源。该坐标访问参照不是20米清除问题的严格最优值。

输出到新的 `results` 子目录；保留全部地图、路线、统计和源码哈希。较小样本仅用于试运行，不会复现十万图均值。
